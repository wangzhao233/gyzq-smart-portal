# 国元证券智能门户 — 新闻数据源配置方案

**编制人员**：王昭
**文档版本**：V3.0
**编制日期**：2026-07-18（重大修订：基于门户API文档重新设计）

> 本文档基于客户OA（SharePoint）REST API + 智能门户数据源API文档（主动拉取v6.0.8 / 数据推送v6.0.8 / 对接指南2.14），指导将OA新闻同步到门户首页。
> **V3.0 修订**：纠正对门户数据源机制的误解——门户主动拉取是POST请求且要求特定JSON格式，不能简单透传SharePoint OData，需要代理层做格式转换。

---

## 1. 技术背景纠正

### 1.1 之前理解的错误

| 之前以为 | 实际情况 |
|---------|---------|
| 门户发GET请求调SP API | 门户发**POST**请求，参数`time/nonce/userId/wxUserId/maxCount/currentPage/typeId` |
| 数据源URL填 `https://portal.oa.gyzq.com/oa-news/...` | 数据源URL填代理服务地址 `http://10.0.63.11:8899/api/news` |
| 透传SharePoint JSON即可 | **必须转换为门户消息列表格式** |
| 门户前端直接渲染 | 门户**后端**代发请求，Nginx代理非必须 |

### 1.2 门户数据源三种模式对比

| 模式 | 方向 | 实时性 | 适用场景 |
|------|------|--------|---------|
| **主动拉取** | 门户→代理→SP | 实时 | ✅ 新闻列表（主推） |
| **数据推送** | 脚本→SP→推送→门户 | 准实时 | 备选 |
| 官方数据源 | 内置 | 实时 | 需部署道一云新闻公告私有化版 |

## 2. 最终方案：主动拉取 + JSON格式转换代理

### 2.1 架构

```
门户后端(POST) → http://10.0.63.11:8899/api/news
                      ↓
              OaProxyServer (Java/Python)
                 ├─ 接收: time, nonce, userId, wxUserId, maxCount, currentPage, typeId
                 ├─ 注入OA Cookie → 调用 SharePoint REST API
                 ├─ 转换: OData JSON → 门户消息列表JSON
                 └─ 返回: {code:0, data:{value:[...]}}
```

### 2.2 门户侧配置（管理员在后台操作）

| 配置项 | 值 |
|--------|-----|
| 数据源类型 | 主动拉取 |
| 组件类型 | 消息列表 |
| 接口URL | `http://10.0.63.11:8899/api/news` |
| 请求方式 | POST（门户自动） |
| 认证方式 | 无需（代理内网调用） |
| 自定义参数 | `typeId=gsdt`（公司动态，可配多个数据源对应不同分类） |

**每个新闻分类创建独立数据源**：

| 数据源名称 | typeId参数 | 对应SharePoint |
|-----------|-----------|---------------|
| OA公司动态 | `gsdt` | `/gsdt/_api/...` |
| OA部门简报 | `bmjb` | `/bmjb/_api/...` |
| OA创新发展 | `cxfz` | `/cxfz/zcdt/_api/...` |
| OA监管动态 | `jgdt` | `/hggl/jgdt/_api/...` |
| OA党建群团 | `djqt` | `/gsdt/djqt/_api/...` |
| OA子公司 | `zgs` | `/gsdt/zgsfzjg/_api/...` |
| OA党建指南 | `lxyz` | `/jdlm/lxyz/_api/...` |

### 2.3 代理服务请求响应规格

**接收（来自门户）**：
```http
POST /api/news
Content-Type: application/x-www-form-urlencoded

time=1752835200&nonce=abc123&userId=xxx&wxUserId=xxx&maxCount=20&currentPage=1&typeId=gsdt
```

**返回（给门户）**：
```json
{
  "code": 0,
  "msg": "执行成功",
  "data": {
    "value": [
      {
        "name": "公司动态",
        "typeId": "gsdt",
        "currPage": 1,
        "pageSize": 20,
        "totalCount": 156,
        "totalPage": 8,
        "value": [
          {
            "title": "国元证券召开2026年中期工作会议",
            "image": "",
            "subTitle": "金融科技部",
            "createTime": "2026-07-15 10:30:00",
            "appName": "老OA",
            "jumpUrl": "http://home.oa.gyzq.com/gsdt/Pages/2026/07/xxx.aspx",
            "publishUser": "系统管理员"
          }
        ]
      }
    ],
    "moreUrl": "http://home.oa.gyzq.com/gsdt/Pages/default.aspx"
  }
}
```

### 2.4 字段映射规则

| SharePoint OData字段 | 门户消息列表字段 | 转换规则 |
|---------------------|----------------|---------|
| `Title` | `title` | 直接映射 |
| 无 | `image` | 固定空字符串（SP页面无封面图） |
| 无 | `subTitle` | 固定"国元证券" |
| `ArticleStartDate` | `createTime` | `/Date(1751827200000)/` → `2026-07-06 14:40:00` |
| 无 | `appName` | 固定"老OA" |
| `FileRef` | `jumpUrl` | `/gsdt/Pages/xxx.aspx` → `http://home.oa.gyzq.com/gsdt/Pages/xxx.aspx` |
| 无 | `publishUser` | 固定空 |

### 2.5 typeId → SharePoint路径映射

| typeId | SP站点 | SP API路径 | 说明 |
|--------|-------|-----------|------|
| `gsdt` | `/gsdt/` | `_api/lists/getbytitle('页面')/items?$orderby=ArticleStartDate desc&$filter=OData__ModerationStatus eq 0` | 公司动态 |
| `bmjb` | `/bmjb/` | 同上 | 部门简报 |
| `cxfz` | `/cxfz/zcdt/` | 同上 | 创新发展 |
| `jgdt` | `/hggl/jgdt/` | 同上 | 监管动态 |
| `djqt` | `/gsdt/djqt/` | 同上 | 党建群团 |
| `zgs` | `/gsdt/zgsfzjg/` | 同上 | 子公司 |
| `lxyz` | `/jdlm/lxyz/` | 同上 | 党建指南 |

## 3. 数据推送模式（备选，用于简单场景）

如果需要，也可以用推送模式：脚本定时从SP拉取 → 转格式 → 推送到门户推送API。

**推送接口**：`POST https://portal.oa.gyzq.com/data_sources/{tenantId}/{dataSourceId}/push`

**推送体示例**：
```json
{
  "secret": "从门户后台获取",
  "jsonData": [
    {
      "infoId": "sp_gsdt_128",
      "title": "国元证券召开2026年中期工作会议",
      "image": "",
      "subTitle": "金融科技部",
      "createTime": "2026-07-15 10:30:00",
      "appName": "老OA",
      "jumpUrl": "http://home.oa.gyzq.com/gsdt/Pages/2026/07/xxx.aspx",
      "dataType": 1
    }
  ]
}
```

**优劣对比**：

| 维度 | 主动拉取（推荐） | 数据推送 |
|------|:--:|:--:|
| 实时性 | ✅ 实时 | ⚠️ 准实时 |
| 复杂度 | 代理需接受POST+转换 | 需管理定时任务+去重 |
| 网络 | 代理在应用服务器 | 需门户推送API可达 |
| 维护 | 代理一个服务 | 代理+定时任务 |
