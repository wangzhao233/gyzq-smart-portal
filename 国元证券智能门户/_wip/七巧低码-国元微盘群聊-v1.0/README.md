# 国元证券 — 七巧低码搭建包 v1.0

> 📅 2026-08-02 | 两个应用：微盘共享空间管理 + 部门群聊管理

## 包含内容

| 目录 | 内容 | 说明 |
|------|------|------|
| `公共函数/` | 3个公共函数 | token获取、token过期处理 |
| `微盘共享空间管理/` | 3个场景脚本 | 空间新建、扩容通知、管理员变更 |
| `部门群聊管理/` | 3个场景脚本 | 创建群、成员管理、群信息变更 |
| `搭建清单.md` | 表单字段表 + 流程 | 6个表单的完整搭建说明 |

## 使用方式

### Step 1：在七巧创建两个应用
1. 登录七巧管理端：`https://qy.do1.com.cn/qiqiao2/console/`
2. 创建应用 `微盘共享空间管理`
3. 创建应用 `部门群聊管理`

### Step 2：按搭建清单建表单
- 打开 `搭建清单.md`，按表单字段表逐个创建表单
- 配置审批流程：申请人提交 → 程文斐审批

### Step 3：粘贴脚本
- 每个表单的「审批流程 → 执行后」位置
- 先将对应 `公共函数/` 下的 token 函数复制到脚本顶部
- 再将对应场景脚本粘贴进去

### Step 4：替换占位符
- 群聊应用的 `getAppChatToken()` 中 secret 需替换为正式值
- 扩容/管理员变更脚本中 程文斐的 userid 需确认替换
