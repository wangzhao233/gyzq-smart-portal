> **日期**：2026年07月21日
> **编制人**：王昭（道一云）

## 一、项目概述

### 1.1 背景

国元证券需要使用七巧低代码搭建应用，实现对企微信盘（私有化部署）部门共享空间的自动化管理。当前微盘共享空间的创建、扩容、管理员变更均需通过企微管理后台手动操作，流程繁琐且缺乏审批管控。本应用旨在将上述操作线上化、流程化、自动化。

### 1.2 目标

| 序号 | 目标 | 描述 | 优先级 |
|:----:|------|------|:------:|
| 1 | 部门共享空间新建自动化 | 部门负责人提交申请 → 审批通过 → 自动调企微API创建共享空间 | P0 |
| 2 | 部门共享空间扩容审批 | 部门负责人提交扩容申请 → 审批通过 → 通知企微管理员手动扩容 | P1 |
| 3 | 部门共享空间管理员变更审批 | 提交变更申请 → 审批通过 → 自动添加新管理员 + 通知企微管理员移除旧管理员 | P1 |

### 1.3 用户角色

| 角色 | 说明 | 使用场景 |
|------|------|---------|
| 部门负责人 | 各业务部门的负责人 | 提交空间新建/扩容/管理员变更申请 |
| IT审批人 | 负责空间管理审批的人员 | 审批各项申请，确认是否通过 |
| 企微系统管理员 | 企微后台管理员 | 收到通知后执行扩容/移除旧管理员等手动操作 |

## 二、功能需求

### 2.1 共享空间新建申请

#### 2.1.1 功能描述

部门负责人填写申请单，提交后进入审批流程。审批通过后，七巧脚本自动调用企微信盘API创建共享空间，并将申请部门及管理员加入空间权限。

#### 2.1.2 表单字段设计

**① 申请信息（申请人填写）**

| 序号 | 字段名 | 控件类型 | 必填 | 说明 | 映射API参数 |
|:----:|--------|---------|:---:|------|:----------:|
| 1 | 空间名称 | 单行文本 | ✅ | 如"信息技术部-共享空间" | `space_name` |
| 2 | 申请部门 | 部门选择器 | ✅ | 选择要创建空间归属的部门 | `auth_info[].departmentid` |
| 3 | 部门负责人 | 自动获取 | ✅ | 系统自动填充当前登录用户 | `auth_info[].userid` (auth=7) |
| 4 | 空间管理员（可选） | 成员选择器 | ❌ | 可额外指定1-2名空间管理员 | `auth_info[].userid` (auth=7) |
| 5 | 申请容量（GB） | 数字 | ❌ | 记录申请的容量需求 | 仅记录，不调API |
| 6 | 申请事由 | 多行文本 | ✅ | 描述申请原因 | — |

**② 系统回填字段（脚本自动写入）**

| 序号 | 字段名 | 说明 |
|:----:|--------|------|
| 7 | 空间ID（spaceid） | 企微API创建成功后返回的空间唯一标识 |
| 8 | 创建结果 | 成功/失败；失败时记录错误原因 |
| 9 | 创建时间 | 脚本执行完成的时间 |

#### 2.1.3 审批流程

```
申请人提交 → [部门负责人审批] → [IT管理员审批] → 审批通过 → 脚本执行
```

- **节点1**：申请人提交（自动跳过，申请人即部门负责人）
- **节点2**：IT管理员审批（指定审批人角色）
- **审批通过后**：触发脚本引擎（执行后），调用企微API

#### 2.1.4 脚本逻辑（审批通过后执行）

```
步骤1: 获取access_token
  └─ GET https://{domain}/cgi-bin/gettoken?corpid=ID&corpsecret=SECRET

步骤2: 调用space_create创建空间
  └─ POST https://{domain}/cgi-bin/wedrive_new/space_create?access_token=TOKEN
  └─ 参数：space_name、auth_info（部门负责人auth=7 + 可选管理员auth=7）

步骤3: 调用space_acl_add添加部门权限
  └─ POST https://{domain}/cgi-bin/wedrive_new/space_acl_add?access_token=TOKEN
  └─ 参数：spaceid、申请部门（auth=1 仅下载）

步骤4: 回填结果
  └─ 成功 → 写入spaceid、创建结果=成功
  └─ 失败 → 写入创建结果=失败+错误原因

步骤5: 发送通知
  └─ 成功 → 站内信通知申请人："共享空间已创建成功，空间ID：xxx"
  └─ 失败 → 站内信通知申请人："创建失败，原因：xxx"
```

#### 2.1.5 权限说明

| 成员 | 类型 | 权限值 | 含义 |
|------|:----:|:-----:|------|
| 部门负责人 | 个人（type=1） | auth=7 | 应用空间管理员（有管理权限） |
| 可选管理员 | 个人（type=1） | auth=7 | 应用空间管理员（最多3人） |
| 申请部门全员 | 部门（type=2） | auth=1 | 仅下载权限 |

### 2.2 共享空间扩容申请

#### 2.2.1 功能描述

部门负责人选择已有的共享空间，提交扩容申请。审批通过后，企微API不支持自动扩容，采用**通知企微管理员手动操作**的模式。

#### 2.2.2 表单字段设计

**① 申请信息（申请人填写）**

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:----:|--------|---------|:---:|------|
| 1 | 选择空间 | 下拉选择/单选 | ✅ | 列出该部门有权限的空间列表 |
| 2 | 当前容量 | 只读显示 | ✅ | 自动显示当前空间容量（如有API可查） |
| 3 | 扩容至（GB） | 数字 | ✅ | 扩容后的目标容量 |
| 4 | 扩容原因 | 多行文本 | ✅ | 描述扩容原因 |

**② 回填字段**

| 序号 | 字段名 | 说明 |
|:----:|--------|------|
| 5 | 处理状态 | 待处理/已处理 |
| 6 | 处理结果 | 扩容完成/退回 |

#### 2.2.3 审批流程

```
申请人提交 → [部门负责人审批] → [IT管理员审批] → 审批通过 → 通知企微管理员
```

- 审批通过后：发送企微消息/站内信通知企微系统管理员去后台手动扩容
- 管理员完成扩容后，在系统中标记处理状态

---

### 2.3 共享空间管理员变更申请

#### 2.3.1 功能描述

当部门负责人变更或管理员离职时，提交管理员变更申请。审批通过后，七巧脚本自动调用企微API将新管理员添加到空间（auth=7），同时通知企微系统管理员移除旧管理员。

#### 2.3.2 表单字段设计

**① 申请信息（申请人填写）**

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:----:|--------|---------|:---:|------|
| 1 | 选择空间 | 下拉选择/单选 | ✅ | 列出需要变更管理员的空间 |
| 2 | 原空间管理员 | 只读显示 | ✅ | 自动显示当前空间的超级管理员列表 |
| 3 | 新管理员 | 成员选择器 | ✅ | 选择新的空间管理员 |
| 4 | 变更原因 | 多行文本 | ✅ | 描述变更原因 |

**② 回填字段**

| 序号 | 字段名 | 说明 |
|:----:|--------|------|
| 5 | 新管理员添加结果 | 成功/失败 |
| 6 | 通知结果 | 已通知企微管理员移除旧管理员 |

#### 2.3.3 脚本逻辑（审批通过后执行）

```
步骤1: 获取access_token
步骤2: 调用space_acl_add添加新管理员
  └─ POST {domain}/cgi-bin/wedrive_new/space_acl_add
  └─ 参数：新管理员userid, auth=7
步骤3: 发送站内信/企微消息
  └─ 通知新管理员：已被添加为空间管理员
  └─ 通知企微系统管理员：请手动移除旧管理员权限
```

## 三、非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 脚本执行应在1分钟内完成（企微API响应时间影响） |
| 安全 | access_token需妥善存储，不可明文硬编码 |
| 可靠性 | API调用失败时应有重试机制和告警通知 |
| 可追溯 | 每次创建/变更记录需留痕，可在七巧中查询历史记录 |

## 四、七巧低码搭建要点

### 4.1 应用结构建议

```
微盘共享空间管理（应用）
├── 空间新建申请（流程表单）
│   ├── 申请表单（字段见2.1.2）
│   ├── 审批流程（2级审批）
│   └── 脚本引擎（审批通过后执行）
├── 空间扩容申请（流程表单）
│   ├── 申请表单（字段见2.2.2）
│   ├── 审批流程（2级审批）
│   └── 消息通知（通知企微管理员）
└── 管理员变更申请（流程表单）
    ├── 申请表单（字段见2.3.2）
    ├── 审批流程（2级审批）
    └── 脚本引擎（审批通过后执行）
```

### 4.2 需要的外部配置

| 配置项 | 说明 | 获取方式 |
|--------|------|---------|
| 企微corpid | 企业微信企业ID | 企微管理后台 |
| 企微corpsecret | 微盘应用的secret | 企微管理后台 → 应用管理 → 微盘 → API配置 |
| access_token缓存 | 每2小时刷新一次，需持久化 | 七巧中建一个系统配置表存储 |
| 企微API域名 | 国元企微私有化部署域名 | 需确认（如 `work.oa.gyzq.com`） |

### 4.3 关键函数用法

```javascript
// 1. 获取access_token
var tokenResp = $.httpclient.sendGet(tokenUrl, {}, {});
var tokenObj = $.json.stringToJsonObject(tokenResp);
var accessToken = tokenObj.getString("access_token");

// 2. 调用POST API（创建空间）
var resp = $.httpclient.sendPost(
    apiUrl,
    {},
    {"Content-Type": "application/json"},
    $.json.objectToJsonString(requestBody)
);

// 3. 发送站内信通知
$.message.sendGeneralStationMessage(
    "标题",
    "内容",
    userId  // 接收人userid
);
```
