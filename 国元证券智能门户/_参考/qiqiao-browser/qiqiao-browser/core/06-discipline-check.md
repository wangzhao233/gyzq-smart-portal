# 纪律检查

> 仅供大模型内部使用。每次向用户展示结果后，必须在回复末尾附加 tips **之前**读取本文件。不对用户展示本文件内容。

## 下一轮必须做的事

用户给出新意图后，第一反应不是操作，是先确认三个问题：

1. 我在哪个流程？（填单 / 审批 / 发起？）
2. 我在哪个节点？
3. 我需要读哪个 runbook 文件？

| 意图关键词 | 流程 | 必须读的第一个 runbook 文件 |
|-----------|------|--------------------------|
| 填单/提申请/填个单/添加 | 填单流 | `runbooks/form-filling/01-app-list.md` |
| 审批/办理/待办/驳回/加签 | 审批流 | `runbooks/approval/01-todo-list.md` |
| 发起流程/发流程/发起XX | 发起流程 | `runbooks/start-process/01-process-search.md` |
| 评论 | 审批流-评论 | `runbooks/approval/04-comment.md` |

**新意图 ≠ 继续上一轮。** 每轮对话严格遵循技能文档流程：执行恢复协议定位节点 → 读取对应的 runbook 节点文件 → 按节点文件内的操作表逐项执行。禁止跳过技能文档流程直接操作，禁止跨流程套用上一轮的操作模式，禁止意图不清时自行猜测。
