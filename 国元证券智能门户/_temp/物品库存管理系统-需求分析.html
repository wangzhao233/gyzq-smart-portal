一、项目概述

1.1 项目背景

为满足企业内部物品库存管理需求，基于七巧Plus低代码平台搭建一套物品库存管理系统。系统需覆盖物品信息管理、出入库操作、库存动态更新、数据报表分析等核心功能，支持多角色权限控制和审批流程。

1.2 建设目标

序号目标说明
1物品信息管理建立物品分类体系和物品档案，支持增删改查
2出入库流程管控通过审批流程规范出入库操作，自动更新库存
3库存实时监控聚合计算当前库存，安全库存预警
4数据可视化报表图表展示库存分布和使用情况
5权限分级管理管理员/仓库员/普通用户三级权限控制

二、用户角色

角色使用场景核心权限
管理员系统管理、数据维护全部权限（增删改查、审批、配置）
仓库员日常出入库操作物品增删改查、出入库操作、库存管理
普通用户物品领用、查看仅查看物品信息和库存

3.3 出入库管理

字段类型必填说明

组件类型说明

3.8 聚合表

基于出入库记录和使用记录，聚合计算物品的实时库存：

配置项说明
主表物品信息
数据源出入库记录（关联物品）、使用记录（关联物品）
入库总量SUM(数量) WHERE 操作类型=入库
出库总量SUM(数量) WHERE 操作类型=出库
使用总量SUM(使用数量)
当前库存初始库存 + 入库总量 - 出库总量 - 使用总量
校验规则当前库存 ≥ 0

七、关键脚本逻辑

7.1 出入库提交后更新库存


1. 获取当前表单的"物品""操作类型""数量"字段值
2. 根据物品ID查询物品表中的当前库存
3. 如果是入库 → 当前库存 += 数量
4. 如果是出库 → 判断库存是否充足
   - 充足 → 当前库存 -= 数量
   - 不足 → 阻止操作，提示用户
5. 保存更新后的库存到物品表
6. 检查是否低于安全库存 → 低于则发送预警通知

7.2 使用记录提交后更新库存


1. 获取"物品""使用数量"
2. 查询物品当前库存
3. 判断库存是否充足 → 充足则扣减，不足则阻止
4. 保存更新

7.3 提交前校验


1. 校验数量 > 0
2. 出库时校验库存 >= 出库数量
3. 不满足条件则阻止提交并提示
