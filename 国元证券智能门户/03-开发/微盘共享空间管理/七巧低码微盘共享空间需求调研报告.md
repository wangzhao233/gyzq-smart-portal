# 七巧低码搭建微盘共享空间管理应用 — 需求调研报告

> 生成日期：2026-07-21  
> 调研范围：七巧低代码平台能力 + 企微私有化API（微盘共享空间）

---

## 一、需求概述

国元证券需要在七巧低码上搭建应用，管理企微微盘的**部门共享空间**，包含三个场景：

| 序号 | 场景 | 简要描述 |
|:----:|------|---------|
| 1 | 新建部门共享空间 | 部门负责人申请 → 审批 → 通过企微API创建共享空间 |
| 2 | 部门共享扩容 | 已完成创建的共享空间 → 审批 → 通过企微API扩容 |
| 3 | 超级管理员变更 | 流程完成后，通知企微系统管理员更换超级管理员 |

| 时机 | 用途 | 对应的需求场景 |

## 三、企微私有化API — 微盘共享空间

### 3.1 前置条件

- 自建应用需配置到"可调用接口的应用"列表中
- 使用该应用secret获取的access_token调用微盘API
- 调用API的应用自动成为创建空间的**超级管理员**

### 3.2 关键API一览

| 接口 | API路径 | 请求方式 | 用途说明 |
|------|---------|:-------:|---------|
| **新建空间** | `/cgi-bin/wedrive_new/space_create` | POST | 创建共享空间（核心接口）|
| **添加成员/部门** | `/cgi-bin/wedrive_new/space_acl_add` | POST | 向空间添加成员或部门 |
| **修改空间安全设置** | `/cgi-bin/wedrive_new/space_setting` | POST | 设置水印、保密模式、分享权限等 |
| **获取空间信息** | `/cgi-bin/wedrive_new/space_info` | POST | 获取空间成员列表和权限 |
| **获取空间信息（含安全设置）** | `/cgi-bin/wedrive_new/new_space_info` | POST | 获取空间详细信息含安全设置 |
| **容量管理（获取）** | `/cgi-bin/wedrive/mng_capacity` | POST | **仅获取盘总容量** |
| **解散空间** | `/cgi-bin/wedrive_new/space_destroy` | POST | 解散共享空间 |
| **重命名空间** | `/cgi-bin/wedrive_new/space_rename` | POST | 修改空间名称 |

### 3.3 API请求地址格式

```
https://{企业微信域名}/cgi-bin/wedrive_new/{接口名}?access_token=ACCESS_TOKEN
```

> 国元证券的实际域名需确认（文档示例为 `work.thermos.com.cn`）

### 3.4 详细API说明

#### ① 新建空间（场景1核心API）

**请求包体：**
```json
{
    "space_name": "部门名称-共享空间",
    "auth_info": [
        {
            "type": 1,
            "userid": "USERID",
            "auth": 7
        },
        {
            "type": 2,
            "departmentid": DEPARTMENTID,
            "auth": 1
        }
    ],
    "space_sub_type": 0
}
```

**参数说明：**
| 参数 | 类型 | 必须 | 说明 |
|------|------|:---:|------|
| space_name | string | 是 | 空间标题 |
| auth_info[].type | uint32 | 否 | 成员类型：1=个人，2=部门 |
| auth_info[].userid | string | 否 | 成员userid（type=1时填写） |
| auth_info[].departmentid | uint32 | 否 | 部门ID（type=2时填写） |
| auth_info[].auth | uint32 | 否 | 1=仅下载 4=可预览 7=应用空间管理员 |
| space_sub_type | uint32 | 否 | 0=普通（目前只支持0） |

**返回：**
```json
{
    "errcode": 0,
    "errmsg": "ok",
    "spaceid": "SPACEID"   // 创建的spaceid，后续扩容/管理需要用
}
```

**关键限制：**
- auth=7（应用空间管理员）最多指定3人，且**不支持设置部门**
- 新建空间时建议指定部门负责人为管理员（auth=7）

#### ② 添加成员/部门到空间

**请求包体：**
```json
{
    "spaceid": "SPACEID",
    "auth_info": [
        {"type": 1, "userid": "USERID1", "auth": 7},
        {"type": 2, "departmentid": DEPARTMENTID1, "auth": 1}
    ]
}
```

**auth权限值：** 1=仅下载 7=应用空间管理员

#### ③ 容量管理

**请求方式：** POST（无参数）
```json
{}
```

**返回：**
```json
{
    "errcode": 0,
    "errmsg": "ok",
    "total_capacity_for_all": 22666689904640,   // 全员容量(Byte)
    "total_capacity_for_vip": 22300038149020    // 专业容量(Byte)
}
```

## 四、三个场景的技术可行性分析

### 场景1：新建部门共享空间 ✅ 完全可行

**流程链：** 部门负责人填写申请表单 → 审批流审批 → 脚本执行后调用企微API

**七巧低码实现方案：**
1. **表单设计**：申请单包含字段：空间名称、申请部门、容量大小、部门负责人等信息
2. **流程配置**：设置审批节点（例如部门经理→IT管理员）
3. **脚本引擎（执行后）**：审批通过后自动执行脚本：
   - 先用 `$.httpclient.sendPost` 调用 `space_create` API创建空间
   - 再用 `$.httpclient.sendPost` 调用 `space_acl_add` API添加部门成员
   - 返回spaceid，存入表单结果字段

**企微API调用时序：**
```
步骤1: 获取access_token（需先存好应用的corpid/corpsecret）
步骤2: POST space_create → 创建空间 → 拿到spaceid
步骤3: POST space_acl_add → 将申请部门添加到空间权限
```

### 场景2：部门共享扩容 ⚠️ 技术上有障碍

**问题所在：** 企微私有化微盘API **没有提供"设置指定空间容量上限"的接口**。

目前容量管理接口（294017）仅有：
- ✅ `mng_capacity` — 获取盘总容量（全员容量 + 专业容量）
- ❌ **没有**设置单个空间容量上限的接口
- ❌ **没有**给指定空间扩容的接口

**建议方案：**
1. **方案A（推荐）**：七巧低码只做**申请审批流程**，审批通过后通过企微消息通知系统管理员，让管理员在**企微管理后台**手动扩容
2. **方案B（需确认）**：如果企微管理端有相关的后台管理API（非微盘模块，属于管理后台API），可进一步调研。目前文档库暂未找到这类接口
3. **方案C（折中）**：在申请表单中记录扩容需求，审批通过后在七巧脚本中调用企微消息通知指定管理员去后台操作

### 场景3：超级管理员变更 ⚠️ 需分步处理

**现状分析：**
- 调用API创建的共享空间，**应用本身自动成为超级管理员**
- auth=7（应用空间管理员）最多3个，但不支持设置部门
- 企微API中**没有"变更超级管理员"的直接接口**

**建议方案：**
1. 在七巧低码建好**变更申请审批流程**
2. 审批通过后，有以下几种处理方式：
   - **方法A：** 由企微管理员在企微管理后台手动变更超级管理员（需通知）
   - **方法B：** 在七巧脚本中使用企微API（添加成员部门接口）将新管理员添加到空间并赋auth=7权限
   - **方法C：** 通过消息通知将变更任务推送给指定系统管理员

## 五、推荐实现思路（整体架构）

### 5.1 应用模块设计

建议在七巧低码中搭建一个「**微盘共享空间管理**」应用，包含以下模块：

| 模块 | 表单 | 流程 | 脚本逻辑 |
|------|------|------|---------|
| 空间新建申请 | 申请部门、空间名称、申请人、部门负责人 | 部门负责人→IT审批 | 审批通过后调space_create |
| 空间扩容申请 | 选择已有空间、申请容量(GB)、扩容原因 | 部门负责人→IT审批 | 审批通过后通知管理员后台操作 |
| 管理员变更申请 | 选择空间、原管理员、新管理员 | 部门负责人→IT审批 | 审批通过后通知管理员后台操作 |

### 5.2 七巧低码脚本调用企微API示例

```javascript
(function(){
    var doc = $.context.getCurrentDocument();
    
    // 1. 获取表单字段值
    var spaceName = doc.getElementByName("空间名称").getValue();
    var departmentId = doc.getElementByName("申请部门").getValue();
    var userId = $.context.getCurrentUserId();  // 申请人
    
    // 2. 获取access_token（需提前配置好corpid/corpsecret）
    var tokenUrl = "https://login.oa.gyzq.com/cgi-bin/gettoken?corpid=ID&corpsecret=SECRET";
    var tokenResp = $.httpclient.sendGet(tokenUrl, {}, {});
    var tokenObj = $.json.stringToJsonObject(tokenResp);
    var accessToken = tokenObj.getString("access_token");
    
    // 3. 调用企微信盘API创建空间
    var createUrl = "https://work.oa.gyzq.com/cgi-bin/wedrive_new/space_create?access_token=" + accessToken;
    var body = {
        "space_name": spaceName,
        "auth_info": [
            {"type": 1, "userid": userId, "auth": 7},
            {"type": 2, "departmentid": parseInt(departmentId), "auth": 1}
        ],
        "space_sub_type": 0
    };
    var resp = $.httpclient.sendPost(createUrl, {}, 
        {"Content-Type": "application/json"}, 
        $.json.objectToJsonString(body)
    );
    
    // 4. 解析返回结果
    var respObj = $.json.stringToJsonObject(resp);
    if (respObj.getInt("errcode") === 0) {
        var spaceId = respObj.getString("spaceid");
        // 5. 将spaceid写回表单字段
        doc.getElementByName("空间ID").setValue(spaceId);
        // 6. 发送通知消息
        $.message.sendGeneralStationMessage(
            "共享空间创建成功",
            "您申请的【" + spaceName + "】共享空间已创建完成，空间ID：" + spaceId,
            userId
        );
    } else {
        $.message.sendGeneralStationMessage(
            "共享空间创建失败",
            "错误信息：" + respObj.getString("errmsg"),
            userId
        );
    }
})()
```

### 5.3 注意事项

1. **access_token管理**：企微access_token有效期7200秒，建议在七巧中用字典表或配置表单持久化，定时刷新
2. **域名确认**：国元证券的企微私有化域名待确认（示例中用的是login.oa.gyzq.com，但国元实际域名可能需要确认）
3. **应用权限配置**：需在企微管理后台将七巧应用配置到"可调用微盘接口的应用"列表中
4. **容量单位**：容量管理接口返回值为B（字节），需转换为GB展示（1GB = 1073741824B）
5. **脚本超时**：新建空间+添加成员涉及多次HTTP调用，需注意1分钟超时限制，若网络延迟高可能超时
