## 1. 登录问题

### 1.1 忘记密码怎么办？

**Q：忘记登录密码怎么办？**

**A：** 您可以通过以下方式重置密码：

1. **自助重置**：在登录页面点击"忘记密码"链接，按照提示输入您的工号或手机号，系统将发送验证码到您的手机，验证通过后即可设置新密码。

2. **联系管理员**：如果自助重置失败，请联系您的部门系统管理员或拨打IT服务热线（程文斐：0551-62201332 / 葛鹏飞：0551-62207154），管理员将协助您重置密码。

3. **注意事项**：
   - 密码要求：至少8位，包含大小写字母、数字和特殊字符
   - 重置后的新密码不能与最近3次使用的密码相同
   - 建议定期更换密码以确保账户安全

### 1.2 登录失败提示

**Q：登录时提示"账号或密码错误"怎么办？**

**A：** 请按以下步骤排查：

1. **检查输入**：
   - 确认工号/用户名输入正确（注意大小写）
   - 检查密码是否包含多余空格
   - 确认使用的是正确的登录入口（门户登录页）

2. **检查账户状态**：
   - 账户是否被锁定（连续5次输入错误密码将锁定30分钟）
   - 账户是否已过期（离职人员账户会被停用）

3. **网络问题**：
   - 检查网络连接是否正常
   - 尝试刷新页面或清除浏览器缓存

4. **其他情况**：
   - 如果提示"账户不存在"，请联系HR确认您的员工信息是否已同步到系统
   - 如果提示"系统维护中"，请稍后再试或关注公告通知

### 1.3 账号被锁定

**Q：账号被锁定了怎么办？**

**A：** 账号锁定通常是由于多次输入错误密码触发了安全机制。您可以：

1. **等待自动解锁**：系统会在30分钟后自动解锁账户
2. **联系管理员**：如需立即解锁，请联系系统管理员，提供您的工号和身份验证信息
3. **预防措施**：
   - 使用"记住密码"功能（在可信设备上）
   - 密码管理工具保存复杂密码
   - 避免在公共设备上登录

### 1.4 密码过期

**Q：提示密码已过期怎么办？**

**A：** 根据公司安全策略，密码有效期为90天。过期后：

1. **强制修改**：系统会自动跳转到密码修改页面
2. **修改要求**：
   - 新密码不能与最近5次使用的密码相同
   - 必须包含大小写字母、数字和特殊字符
   - 长度8-16位
3. **修改后**：使用新密码重新登录即可

## 2. 客户端问题

### 2.1 元信下载安装

**Q：如何下载安装元信客户端？**

**A：** 元信是国元证券私有化部署的企业微信定制版客户端，安装步骤如下：

1. **下载方式**：
   - **内部下载**：访问公司内部门户，在"常用工具"中找到"元信客户端下载"
   - **扫码下载**：扫描内部公告中的二维码（适用于手机端）
   - **管理员分发**：IT部门统一下发安装包

2. **安装步骤**：
   - **Windows版**：双击安装包，按向导完成安装，安装路径建议使用默认位置
   - **Mac版**：拖拽应用程序到Applications文件夹
   - **手机版**：从应用商店搜索"国元元信"或扫描二维码下载

3. **安装后配置**：
   - 首次启动需要输入公司域名：`mc.oa.gyzq.com`
   - 使用您的SSO账号密码登录
   - 允许必要的系统权限（通知、摄像头等）

### 2.2 消息推送不工作

**Q：手机收不到消息推送怎么办？**

**A：** 消息推送问题可能由多种原因导致，请按以下步骤排查：

1. **检查系统权限**：
   - **iOS**：设置 → 通知 → 国元元信 → 允许通知
   - **Android**：设置 → 应用管理 → 国元元信 → 通知管理 → 开启通知
   - **华为/小米等**：在电池设置中关闭"省电优化"，将元信加入白名单

2. **检查应用设置**：
   - 打开元信 → 设置 → 新消息通知 → 确保开启所有通知选项
   - 检查"勿扰模式"是否开启
   - 确认"消息免打扰"未对特定群组开启

3. **网络问题**：
   - 确保手机网络连接正常
   - 尝试切换Wi-Fi和移动数据
   - 检查VPN连接状态（如需要）

4. **其他排查**：
   - 重启手机和元信应用
   - 检查是否有系统更新
   - 卸载重装元信客户端

### 2.3 客户端闪退

**Q：元信客户端频繁闪退怎么办？**

**A：** 客户端闪退可能是由于系统兼容性或资源不足导致：

1. **常见原因**：
   - 设备内存不足
   - 系统版本过低
   - 应用缓存损坏
   - 与其他软件冲突

2. **解决方法**：
   - **清理缓存**：设置 → 存储 → 清理缓存
   - **更新系统**：确保操作系统版本符合要求
     - Windows：Windows 10及以上
     - Mac：macOS 10.15及以上
     - Android：Android 8.0及以上
     - iOS：iOS 12及以上
   - **重装应用**：完全卸载后重新安装最新版本
   - **检查兼容性**：关闭可能冲突的软件（如杀毒软件、防火墙）

3. **收集信息**：
   - 记录闪退时间和操作步骤
   - 截取错误提示（如有）
   - 反馈给IT支持团队

## 3. 门户使用问题

### 3.1 功能入口找不到

**Q：门户中找不到需要的功能怎么办？**

**A：** 智能门户的功能入口可能因权限配置而有所不同：

1. **检查位置**：
   - **顶部导航栏**：常用功能如待办、消息、新闻公告
   - **左侧菜单**：按业务分类的功能模块
   - **工作台**：个性化配置的常用应用
   - **搜索功能**：使用顶部搜索框快速查找功能

2. **权限问题**：
   - 部分功能需要特定权限才能显示
   - 联系部门系统管理员申请相应权限
   - 权限申请流程：提交申请 → 部门审批 → 管理员配置

3. **个性化设置**：
   - 在"工作台设置"中自定义常用应用
   - 拖拽调整应用位置
   - 添加/移除快捷方式

### 3.2 页面加载慢

**Q：门户页面加载很慢怎么办？**

**A：** 页面加载慢可能影响工作效率，请尝试以下优化方法：

1. **网络优化**：
   - 检查网络连接速度
   - 尝试刷新页面（Ctrl+F5强制刷新）
   - 清除浏览器缓存和Cookie

2. **浏览器优化**：
   - 使用推荐浏览器：Chrome 80+、Firefox 75+、Edge 80+
   - 关闭不必要的浏览器扩展
   - 确保浏览器版本最新

3. **系统优化**：
   - 关闭不必要的后台应用
   - 检查设备性能（内存、CPU使用率）
   - 尝试在非高峰时段访问

4. **其他建议**：
   - 使用有线网络代替无线网络
   - 避免同时打开多个标签页
   - 定期重启设备

### 3.3 数据不同步

**Q：门户中的数据与实际不一致怎么办？**

**A：** 数据同步问题需要根据具体情况处理：

1. **同步机制说明**：
   - HR系统 → 门户 → 元信：每天晚上12点自动同步
   - 部分数据实时同步（如待办事项）
   - 部分数据延迟同步（如组织架构）

2. **排查步骤**：
   - **确认数据类型**：不同数据同步频率不同
   - **检查时间点**：是否在同步周期内
   - **验证来源**：数据源是否正确

3. **常见问题处理**：
   - **个人信息错误**：联系HR更新信息，等待下次同步
   - **组织架构未更新**：新入职/调岗员工需等待同步周期
   - **应用数据延迟**：第三方应用数据由各自系统管理

4. **紧急情况**：
   - 如需立即同步，联系系统管理员手动触发
   - 记录具体问题和截图以便排查

## 4. 消息中心问题

### 4.1 消息收不到

**Q：为什么收不到系统消息？**

**A：** 消息中心支持双通道推送（门户+企微），请按以下步骤排查：

1. **检查通知设置**：
   - **门户设置**：个人设置 → 消息通知 → 确保开启所需消息类型
   - **元信设置**：设置 → 新消息通知 → 开启相应通知

2. **消息类型确认**：
   - **系统通知**：重要系统公告和提醒
   - **待办提醒**：待办事项相关通知
   - **业务消息**：具体业务流程消息
   - **新闻公告**：公司新闻和公告

3. **权限检查**：
   - 确认您的账户有接收相关消息的权限
   - 部分消息需要特定角色才能接收

4. **技术排查**：
   - 检查网络连接
   - 确认消息中心服务正常运行
   - 联系IT支持团队

### 4.2 如何撤回消息

**Q：发送的消息可以撤回吗？**

**A：** 消息撤回功能取决于消息类型和发送时间：

1. **可撤回的消息**：
   - **即时消息**：发送后2分钟内可撤回
   - **群消息**：仅发送者可撤回自己的消息
   - **公告消息**：管理员可撤回未读公告

2. **撤回步骤**：
   - 右键点击消息 → 选择"撤回"
   - 确认撤回操作
   - 撤回成功后，消息将显示"已撤回"提示

3. **限制说明**：
   - 超过2分钟的消息无法撤回
   - 已读消息无法撤回（部分情况）
   - 系统消息无法撤回

4. **替代方案**：
   - 对于无法撤回的消息，可以发送更正说明
   - 管理员可以协助处理特殊情况

### 4.3 消息类型区别

**Q：不同类型的消息有什么区别？**

**A：** 消息中心支持多种消息类型，各有特点：

1. **即时消息**：
   - 实时一对一或群聊
   - 支持文字、图片、文件
   - 有已读状态（部分功能）

2. **系统通知**：
   - 系统自动发送
   - 重要性高，需要关注
   - 通常有操作指引

3. **待办提醒**：
   - 与待办事项关联
   - 包含截止时间和优先级
   - 可设置提醒频率

4. **业务消息**：
   - 与具体业务流程相关
   - 包含业务单据链接
   - 需要处理或确认

5. **新闻公告**：
   - 公司正式通知
   - 有时效性
   - 通常需要阅读确认

## 5. 新闻公告问题

### 5.1 看不到公告

**Q：为什么看不到某些公告？**

**A：** 公告可见性由权限和发布范围决定：

1. **权限检查**：
   - 公告按部门、岗位、角色设置发布范围
   - 确认您是否在公告的目标范围内
   - 联系部门管理员确认权限配置

2. **公告分类**：
   - **全员公告**：所有员工可见
   - **部门公告**：特定部门可见
   - **角色公告**：特定角色可见
   - **定向公告**：指定人员可见

3. **查看方式**：
   - **门户首页**：新闻公告模块
   - **公告中心**：完整公告列表
   - **消息中心**：重要公告推送
   - **搜索功能**：关键词搜索公告

4. **其他原因**：
   - 公告可能已过期下架
   - 浏览器缓存问题
   - 网络加载延迟

### 5.2 公告过期了

**Q：过期的公告还能查看吗？**

**A：** 过期公告的处理方式如下：

1. **查看历史公告**：
   - **公告中心**：点击"历史公告"或"已结束公告"
   - **搜索功能**：使用关键词搜索历史公告
   - **归档目录**：部分公告会归档到知识库

2. **保存期限**：
   - 重要公告：永久保存
   - 一般公告：保存1年
   - 临时公告：保存3个月

3. **下载保存**：
   - 公告详情页提供下载按钮
   - 支持PDF、Word格式导出
   - 建议重要公告及时下载保存

4. **找回方法**：
   - 如果找不到过期公告，联系公告发布部门
   - 管理员可以协助查找历史公告

### 5.3 如何搜索公告

**Q：如何快速找到需要的公告？**

**A：** 高效搜索公告的技巧：

1. **搜索入口**：
   - **全局搜索**：顶部搜索框，选择"公告"类型
   - **公告中心**：公告列表页的搜索框
   - **高级搜索**：更多筛选条件

2. **搜索技巧**：
   - **关键词**：使用公告标题或内容中的关键词
   - **时间范围**：设置发布或过期时间
   - **发布部门**：按部门筛选
   - **公告类型**：按类型筛选

3. **筛选条件**：
   - 发布时间：最近一周、一个月、三个月
   - 公告状态：进行中、已结束、全部
   - 重要程度：普通、重要、紧急

4. **收藏功能**：
   - 重要公告可以收藏
   - 收藏夹中集中管理
   - 支持分类整理

## 6. 并行使用问题

### 6.1 SaaS企微和元信区别

**Q：SaaS企业微信和元信有什么区别？**

**A：** 元信是国元证券私有化部署的企业微信定制版，主要区别如下：

1. **部署方式**：
   - **SaaS企微**：腾讯云托管，共享基础设施
   - **元信**：私有化部署，独立服务器，数据完全隔离

2. **数据安全**：
   - **SaaS企微**：数据存储在腾讯云，受腾讯安全策略保护
   - **元信**：数据存储在公司内部，符合金融行业监管要求

3. **定制能力**：
   - **SaaS企微**：有限的界面和功能定制
   - **元信**：深度定制，包括Logo、界面、功能模块

4. **功能差异**：
   - **基础功能**：基本相同，包括通讯、群聊、应用
   - **高级功能**：元信支持更多企业级功能
   - **集成能力**：元信与内部系统集成更紧密

### 6.2 数据是否同步

**Q：SaaS企微和元信的数据会同步吗？**

**A：** 数据同步情况如下：

1. **不同步的数据**：
   - **聊天记录**：完全独立，不互通
   - **文件传输**：各自独立存储
   - **应用数据**：第三方应用数据不互通

2. **可能同步的数据**：
   - **组织架构**：基础架构可能同步（取决于配置）
   - **通讯录**：部分基础信息可能同步
   - **公告信息**：重要公告可能同步发布

3. **同步机制**：
   - 需要管理员配置同步策略
   - 同步频率和范围可自定义
   - 同步过程有日志记录

4. **建议**：
   - 重要数据建议双平台备份
   - 关键沟通建议使用主平台
   - 定期检查数据一致性

### 6.3 过渡期多久

**Q：从SaaS企微过渡到元信需要多长时间？**

**A：** 过渡期安排如下：

1. **过渡阶段**：
   - **并行期**：2026年7月20日起，新旧系统长期并行运行（预计至2026年底）
   - **说明**：老OA和SaaS企业微信均不下线，仅部分业务逐步迁移至新系统
   - **通知**：如有系统调整将提前30天通知

2. **过渡期安排**：
   - **双平台运行**：两个平台同时使用
   - **数据迁移**：重要数据逐步迁移
   - **用户培训**：分批次培训新系统使用
   - **问题收集**：收集并解决过渡期问题

3. **切换标准**：
   - 元信系统稳定运行30天
   - 核心功能测试通过
   - 用户培训完成率90%以上

## 7. 组织架构同步问题

### 7.1 信息没更新

**Q：个人信息或组织架构信息没更新怎么办？**

**A：** 组织架构信息同步流程和问题处理：

1. **同步流程**：
   - **数据源**：HR系统
   - **同步路径**：HR系统 → 门户 → 元信
   - **同步频率**：每天晚上12点
   - **同步内容**：员工基本信息、部门架构、汇报关系

2. **信息未更新原因**：
   - **同步周期**：新信息需等待下次同步
   - **数据错误**：HR系统中信息有误
   - **同步失败**：技术问题导致同步中断
   - **权限限制**：部分信息需特殊权限查看

3. **处理步骤**：
   - **确认时间**：是否在同步周期内
   - **检查源头**：HR系统信息是否正确
   - **手动触发**：联系管理员手动同步
   - **反馈问题**：记录具体问题和截图

4. **紧急情况**：
   - 重要信息变更可申请紧急同步
   - 需要部门负责人确认
   - 管理员在2小时内处理

### 7.2 新入职员工多久能用

**Q：新入职员工多久可以使用系统？**

**A：** 新员工系统开通流程：

1. **开通时间**：
   - **信息录入**：入职当天HR录入系统
   - **数据同步**：当晚12点同步到门户
   - **系统开通**：次日早上8点可正常使用
   - **特殊情况**：当天入职当天开通（需申请）

2. **开通内容**：

### 7.3 离职人员处理

**Q：离职人员的系统权限如何处理？**

   - **文件交接**：重要文件转移给接替者

   - **群组处理**：自动退出工作群组
   - **待办处理**：未完成待办转移给接替者

4. **注意事项**：
   - 离职前确保重要数据备份
   - 及时完成工作交接
   - 配合IT部门完成权限回收
