# oa-news-sync — 子项目上下文

> 老OA新闻同步到智能门户 — 开发子项目
> 父项目: 国元证券智能门户 | 创建: 2026-07-20

## 目标

将老OA（SharePoint on-premises, `home.oa.gyzq.com`）的新闻数据通过智能门户数据源展示到首页，覆盖8个新闻分类。

## 技术方案

门户主动拉取(POST) → Java代理(10.0.63.11:8899) → SharePoint REST API → 格式转换 → 返回门户消息列表JSON

详见 `02-方案/新闻数据源配置方案.md`
