## 应用1：微盘共享空间管理

### 表单1：共享空间新建

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 空间名称 | 单行文本 | ✅ | 如"信息技术部-共享空间" |
| 2 | 申请部门 | 部门选择器 | ✅ | |
| 3 | 空间管理员（可选） | 成员选择器（多选，最多2人） | ❌ | |
| 4 | 申请容量（GB） | 数字 | ❌ | 仅记录 |
| 5 | 申请事由 | 多行文本 | ✅ | |
| 6 | 空间ID（spaceid） | 单行文本（只读） | - | 脚本回填 |
| 7 | 创建结果 | 单行文本（只读） | - | 脚本回填 |
| 8 | 创建时间 | 日期时间（只读） | - | 脚本回填 |

审批流程：申请人提交 → IT管理员（程文斐）审批
脚本：执行后 → 复制 `公共函数/getWeDriveToken.js` + `微盘共享空间管理/场景1-共享空间新建.js`

### 表单2：共享空间扩容

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 选择空间 | 下拉选择 | ✅ | |
| 2 | 当前容量 | 只读显示 | - | |
| 3 | 扩容至（GB） | 数字 | ✅ | |
| 4 | 扩容原因 | 多行文本 | ✅ | |
| 5 | 处理状态 | 单选（只读） | - | 待处理/已处理 |
| 6 | 处理结果 | 单行文本（只读） | - | |

审批流程：同上
脚本：执行后 → `公共函数/getWeDriveToken.js` + `微盘共享空间管理/场景2-共享空间扩容.js`

### 表单3：空间管理员变更

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 选择空间 | 下拉选择 | ✅ | |
| 2 | 原空间管理员 | 只读显示 | - | |
| 3 | 新管理员 | 成员选择器 | ✅ | |

## 应用2：部门群聊管理

### 表单1：创建部门群

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 群名称 | 单行文本 | ✅ | 如"信息技术部-部门群" |
| 2 | 所属部门 | 部门选择器 | ✅ | 自动拉该部门全员 |
| 3 | 群主 | 成员选择器 | ✅ | 默认申请人 |
| 4 | 额外成员 | 成员选择器（多选） | ❌ | |
| 5 | 申请事由 | 多行文本 | ✅ | |
| 6 | 群ID（chatid） | 单行文本（只读） | - | 脚本回填 |
| 7 | 创建结果 | 单行文本（只读） | - | 脚本回填 |
| 8 | 群成员数 | 数字（只读） | - | 脚本回填 |

审批流程：同上
脚本：执行后 → `公共函数/getAppChatToken.js` + `部门群聊管理/场景1-创建部门群.js`
⚠️ 需先替换 `getAppChatToken()` 中的 secret 占位符

### 表单2：群成员管理

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 选择群 | 下拉选择 | ✅ | |
| 2 | 操作类型 | 单选 | ✅ | 添加成员 / 移除成员 |
| 3 | 选择成员 | 成员选择器（多选） | ✅ | |
| 4 | 操作原因 | 多行文本 | ✅ | |

审批流程：同上
脚本：执行后 → `公共函数/getAppChatToken.js` + `部门群聊管理/场景2-群成员管理.js`

### 表单3：群信息变更

| 序号 | 字段名 | 控件类型 | 必填 | 说明 |
|:--:|--------|---------|:--:|------|
| 1 | 选择群 | 下拉选择 | ✅ | |
| 2 | 操作类型 | 单选 | ✅ | 改群名 / 改群主 / 解散群 |
| 3 | 新群名 | 单行文本 | 条件 | 仅改群名时 |
| 4 | 新群主 | 成员选择器 | 条件 | 仅改群主时 |
| 5 | 变更原因 | 多行文本 | ✅ | |
