## 第1步：验证代理服务连通性

在门户应用服务器或能访问 `10.0.63.11` 的机器上执行：

```bash
# 健康检查
curl http://10.0.63.11:8899/health

# 模拟门户POST请求（公司动态）
curl -X POST http://10.0.63.11:8899/api/news \
  -d "typeId=gsdt&maxCount=5&currentPage=1" \
  -H "Content-Type: application/x-www-form-urlencoded"
```

**预期返回**：
```json
{
  "code": 0,
  "msg": "执行成功",
  "data": {
    "value": [{
      "name": "公司动态",
      "typeId": "gsdt",
      "currPage": 1,
      "pageSize": 5,
      "totalCount": 156,
      "totalPage": 32,
      "value": [
        {
          "title": "新闻标题",
          "content": "<p>文章HTML正文内容</p>",
          "image": "",
          "subTitle": "国元证券",
          "createTime": "2026-07-15 10:30:00",
          "appName": "老OA",
          "jumpUrl": "http://home.oa.gyzq.com/gsdt/Pages/xxx.aspx",
          "publishUser": ""
        }
      ]
    }],
    "moreUrl": "http://home.oa.gyzq.com/gsdt/Pages/default.aspx"
  }
}
```

> **注意**：部分分类（如部门简报、创新发展）的文章为附件形式，`content` 字段可能为空字符串。

如果返回 `"code": 0` 且 `value` 数组非空，说明代理服务正常。

## 第3步：绑定消息列表组件

1. 进入 **门户中心** → **门户装修** → **首页编辑**
2. 找到消息列表组件（或新建一个）
3. 在组件设置中：
   - **数据源类型**：选择「消息列表」
   - **数据源**：选择上面创建的数据源（如「OA公司动态」）
   - **显示条数**：建议 5-10 条
   - **标题字段**：`title`
   - **时间字段**：`createTime`
   - **链接字段**：`jumpUrl`
   - **副标题字段**：`subTitle`

4. 如果首页有多个新闻区域，重复绑定不同数据源

---

## 第4步：预览与发布

1. 点击 **预览** 按钮，检查新闻列表是否正常显示
2. 检查：
   - 标题是否正确显示
   - 时间格式是否为 `yyyy-MM-dd HH:mm:ss`
   - 点击标题是否能跳转到OA新闻详情页
   - 分页是否正常（如果有）
3. 确认无误后点击 **发布**

## 常见问题

### Q1: 数据源测试返回空数组

**原因**：代理服务可能未正确登录OA

**解决**：
```bash
# 检查代理日志
journalctl -u oa-proxy -n 50

# 检查Cookie是否有效
curl http://10.0.63.11:8899/health
```

### Q2: 返回 401 错误

**原因**：OA账号密码错误或Cookie过期

**解决**：
1. 检查 `oa-proxy.properties` 中的账号密码
2. 重启代理服务：`systemctl restart oa-proxy`

### Q3: 返回 502 错误

**原因**：代理服务未启动

**解决**：
```bash
systemctl start oa-proxy
systemctl status oa-proxy
```

### Q4: 新闻列表不更新

**原因**：门户缓存或代理Cookie过期

**解决**：
1. 检查代理日志确认请求是否到达
2. 清除门户缓存（如果有）
3. 检查代理Cookie刷新日志
