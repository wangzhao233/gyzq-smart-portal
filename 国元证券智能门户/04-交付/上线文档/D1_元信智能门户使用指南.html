2. 系统概述

2.1 元信简介

元信是国元证券私有化部署的企业即时通讯工具，您可以通过它进行同事间沟通、接收工作通知、访问内部应用。

主要功能：

  • 即时通讯：与同事进行文字、语音、视频沟通
  • 工作台：集中访问门户、七巧等内部应用
  • 消息通知：接收来自各业务系统的推送通知
  • 通讯录：查看公司组织架构和同事联系方式

2.2 智能门户简介

智能门户是国元证券的内部办公平台，您可以通过它完成日常办公的大部分操作。

主要功能：

  • 新闻公告：查看公司发布的各类通知和公告
  • 待办中心：集中查看和处理各类待办事项
  • 日程中心：管理个人日程和会议安排
  • 消息中心：查看系统推送的各类消息通知

2.3 七巧低码简介

七巧低码是低代码开发平台，支持快速搭建业务应用，无需编写代码即可完成表单、流程、报表等功能的配置。

主要功能：

  • 表单设计：通过拖拽方式快速创建业务表单
  • 流程配置：可视化配置审批流程
  • 报表生成：自动生成数据统计报表
  • 应用搭建：快速构建完整的业务应用

2.4 系统架构说明

三个系统之间的关系如下：


HR系统 → 智能门户 → 元信

人员信息的同步方向为：HR系统每天晚上12点将最新组织架构和人员信息同步到门户，门户再同步到元信。

3.2.2 安装客户端

Windows系统安装步骤：

  1. 双击下载的安装包文件（.exe格式）
  2. 在弹出的安全提示中点击"是"
  3. 选择安装路径，建议使用默认路径
  4. 点击"安装"，等待安装完成
  5. 点击"完成"，启动元信客户端

Mac系统安装步骤：

  1. 双击下载的.dmg文件
  2. 将元信图标拖拽到"应用程序"文件夹
  3. 在"应用程序"中找到并双击元信图标启动
  4. 如遇安全提示，前往"系统设置→隐私与安全性"允许运行

Linux系统安装步骤：

根据您的Linux发行版选择对应安装包格式：

  • Debian/Ubuntu/统信UOS：双击.deb包安装，或使用命令 sudo dpkg -i 包名.deb
  • Red Hat/CentOS/银河麒麟：使用命令 sudo rpm -ivh 包名.rpm
  • 通用格式：下载.AppImage文件，赋予执行权限后双击运行

3.3 首次登录流程

3.3.1 移动端登录流程

操作步骤：

  1. 打开元信客户端App
  2. 在登录页面输入组织机构域：000728
  3. 点击"开始使用"
  4. 选择"账号密码登录"
  5. 输入您的账号和密码（账号密码需找企微平台管理员获取）
  6. 点击"登录"按钮
  7. 系统验证通过后，进入元信主界面
  8. 首次登录会提示您完善个人信息（如头像、手机号等），请根据提示完成设置

3.3.2 PC端登录流程

操作步骤：

  1. 打开元信PC客户端
  2. 在登录界面点击右上角的齿轮按钮进入设置界面
  3. 设置服务器：选择"手动设置"
  4. 输入内网服务器地址：mc.oa.gyzq.com，端口：443
  5. 确认设置后返回登录页面
  6. 输入您的账号和密码（账号密码需找企微平台管理员获取）
  7. 点击"登录"按钮
  8. 系统验证通过后，进入元信主界面

3.3.3 PC端快捷入口

登录PC端元信后，您可以通过以下方式访问管理后台：

  1. 点击PC端左上角的任务头像
  2. 选择"快捷入口"
  3. 点击"登录管理台"

3.3.4 注意事项

  • 如果忘记密码，请联系IT服务台重置
  • 首次登录后建议立即修改初始密码
  • 如遇登录异常，请检查网络连接或联系技术支持

3.5 访问智能门户和七巧

登录元信后，您可以通过工作台访问智能门户和七巧低码平台。系统采用前端H5单点登录方式，实现无缝认证。

3.5.1 单点登录说明

平台登录方式说明
移动端通过企微工作台应用入口自动携带code参数，无需手动输入凭证
PC端通过企微工作台应用入口自动跳转并完成认证

3.5.2 操作步骤

移动端访问：

  1. 在元信移动端底部导航栏点击"工作台"
  2. 在工作台页面找到"智能门户"或"七巧低码"图标
  3. 点击图标，系统将自动完成单点登录并跳转到对应应用
  4. 无需再次输入账号密码

PC端访问：

  1. 在元信PC端底部导航栏点击"工作台"
  2. 在工作台页面找到"智能门户"或"七巧低码"图标
  3. 点击图标，系统将自动跳转并完成单点登录
  4. 无需再次输入账号密码

3.6 Web浏览器访问方式

除了通过元信客户端访问智能门户外，您还可以直接通过Web浏览器访问。

3.6.1 访问地址

智能门户Web访问地址：https://portal.oa.gyzq.com/

操作步骤：

  1. 打开浏览器（推荐使用Chrome、Edge等现代浏览器）
  2. 在地址栏输入智能门户访问地址
  3. 系统将跳转至SSO登录页面
  4. 输入您的工号和SSO密码
  5. 点击"登录"按钮，即可进入智能门户

3.6.2 忘记密码功能

如果忘记密码，可通过以下方式重置：

  1. 在登录页面点击"忘记密码"链接
  2. 输入您的手机号码
  3. 点击"获取验证码"按钮
  4. 输入收到的短信验证码
  5. 设置新密码并确认
  6. 点击"确定"按钮，密码重置成功

注意事项：

  • 手机号需为HR系统中登记的手机号码
  • 验证码有效期为5分钟
  • 新密码需满足密码复杂度要求

3.6.3 修改密码功能

登录后可通过以下方式修改密码：

  1. 在门户顶部导航栏点击您的头像
  2. 选择"个人设置"
  3. 在"账号安全"或"密码管理"中点击"修改密码"
  4. 输入当前密码（验证身份）
  5. 输入新密码并确认
  6. 点击"保存"按钮

5. 消息中心使用

5.1 消息中心概述

消息中心是您接收各类系统通知的统一入口，支持以下双通道推送：

推送通道说明
门户（PORTAL）通过智能门户内部推送，登录门户后可查看
企微（QW）通过元信客户端推送，可实时接收通知

特别说明：消息中心不提供已读追踪功能，即系统不会记录您是否已阅读某条消息。

5.2 查看消息

操作步骤：

  1. 在门户首页点击"消息中心"入口，或点击顶部导航栏的消息图标
  2. 进入消息列表页面，消息按时间倒序排列
  3. 点击任意消息可查看详情内容
  4. 未读消息会以蓝色圆点或加粗字体标识

5.3 消息分类

消息中心的消息按类型分为以下几类：

消息类型图标说明
系统通知🔔系统维护、功能更新等通知
待办提醒✅待办事项的提醒通知
公告通知📢新发布的公告提醒
日程提醒📅即将开始的日程提醒
审批通知📋审批流程相关的通知

5.4 消息筛选与搜索

按类型筛选：

  1. 在消息中心页面顶部，找到筛选栏
  2. 点击消息类型标签（如"系统通知""待办提醒"等）
  3. 列表将只显示对应类型的消息

搜索消息：

  1. 在消息中心页面顶部的搜索框中输入关键词
  2. 按回车键或点击搜索按钮
  3. 系统将显示包含关键词的消息列表

5.5 消息管理

批量操作：

  1. 勾选需要操作的消息（支持多选）
  2. 点击"全部已读"按钮，将选中消息标记为已读状态
  3. 点击"删除"按钮，删除选中的消息

单条操作：

  1. 将鼠标悬停在消息右侧
  2. 点击"已读"按钮标记为已读
  3. 点击"删除"按钮删除该消息

6. 新闻公告

6.1 查看公告

操作步骤：

  1. 在门户首页点击"新闻公告"入口
  2. 进入公告列表页面，公告按发布时间倒序排列
  3. 点击公告标题可查看公告详情
  4. 公告详情页包含标题、发布时间、发布部门、正文内容等信息

6.2 公告分类

新闻公告按类型分为以下几类：

公告类型说明示例
公司通知公司级重要通知年度工作安排、放假通知
部门通知部门级通知部门会议通知、工作安排
人事公告人事相关公告人员调动、任职公告
行政公告行政事务公告办公环境变更、设施维护
IT公告信息技术相关公告系统维护通知、功能更新

6.3 公告筛选

按分类筛选：

  1. 在公告列表页面左侧或顶部找到分类标签
  2. 点击需要查看的分类（如"公司通知""人事公告"等）
  3. 列表将只显示对应分类的公告

按时间筛选：

  1. 在公告列表页面找到时间筛选区域
  2. 选择时间范围（如"最近一周""最近一月"等）
  3. 列表将只显示指定时间范围内的公告

6.4 公告搜索

操作步骤：

  1. 在公告列表页面顶部的搜索框中输入关键词
  2. 按回车键或点击搜索按钮
  3. 系统将显示标题或正文包含关键词的公告

搜索技巧：

  • 使用精确关键词可提高搜索准确性
  • 可组合使用分类筛选和关键词搜索

7. 待办中心

7.1 查看待办

操作步骤：

  1. 在门户首页点击"待办中心"入口，或点击首页右侧的待办提醒卡片
  2. 进入待办列表页面，待办事项按紧急程度和时间排序
  3. 列表中显示待办标题、来源系统、发起时间、截止时间等信息
  4. 点击待办标题可查看待办详情

7.2 待办状态说明

状态说明
待办需要您处理的待办事项
待阅需要您查看的待阅事项
已办已处理完成的待办事项
超期提醒超过截止时间仍未处理的待办

7.3 处理待办

操作步骤：

  1. 在待办列表中点击需要处理的待办标题
  2. 查看待办详情，了解具体要求和所需材料
  3. 根据待办类型进行相应操作：
    - 审批类待办：查看申请内容，点击"同意"或"驳回"
    - 任务类待办：完成指定任务后点击"提交"或"完成"
    - 确认类待办：确认内容后点击"已确认"
  4. 处理完成后，待办状态自动更新为"已办"

7.4 待办筛选

按状态筛选：

  1. 在待办列表页面顶部找到状态筛选标签
  2. 点击"待办""待阅""已办"等标签
  3. 列表将只显示对应状态的待办

按来源筛选：

  1. 在待办列表页面找到来源筛选区域
  2. 选择来源系统（如"OA系统""HR系统"等）
  3. 列表将只显示来自该系统的待办

7.5 待办提醒设置

操作步骤：

  1. 进入"个人设置"页面
  2. 找到"通知设置"或"待办提醒"选项
  3. 设置提前提醒时间（如提前15分钟、1小时、1天等）
  4. 选择提醒方式（门户提醒、元信推送等）
  5. 保存设置

8. 日程中心

8.1 查看日程

操作步骤：

  1. 在门户首页点击"日程中心"入口
  2. 进入日程页面，默认显示今日日程
  3. 日程以时间轴形式展示，显示日程标题、时间、地点等信息
  4. 点击日程可查看详情

8.2 日程视图切换

日程中心支持以下视图模式：

视图模式说明
日视图显示某一天的所有日程
周视图显示一周七天的日程安排
月视图显示整月的日程概览
列表视图以列表形式显示所有日程

切换视图：

  1. 在日程页面顶部找到视图切换按钮
  2. 点击"日""周""月""列表"等按钮
  3. 页面将切换到对应的视图模式

8.3 创建日程

操作步骤：

  1. 在日程中心页面点击"新建日程"或"+"按钮
  2. 在弹出的日程编辑页面填写以下信息：
    - 日程标题：输入日程名称（必填）
    - 开始时间：选择日程开始的日期和时间（必填）
    - 结束时间：选择日程结束的日期和时间（必填）
    - 地点：输入日程地点（选填）
    - 描述：输入日程的详细说明（选填）
    - 提醒：设置提前提醒时间（选填）
    - 参与人：添加参与此日程的同事（选填）
  3. 点击"保存"按钮，日程创建成功

8.4 编辑日程

操作步骤：

  1. 在日程页面点击需要编辑的日程
  2. 在日程详情页点击"编辑"按钮
  3. 修改日程信息（标题、时间、地点等）
  4. 点击"保存"按钮，日程更新成功

8.5 删除日程

操作步骤：

  1. 在日程页面点击需要删除的日程
  2. 在日程详情页点击"删除"按钮
  3. 在确认对话框中点击"确定"
  4. 日程删除成功

注意事项：

  • 如果您是日程的创建者，可以删除该日程
  • 如果日程有其他参与人，删除后会通知参与人
  • 已过期的日程会自动归档，不会显示在默认视图中

8.6 日程共享与协作

邀请参与人：

  1. 创建或编辑日程时，在"参与人"字段输入同事姓名
  2. 从搜索结果中选择参与人
  3. 保存日程后，参与人将收到日程邀请通知

查看团队日程：

  1. 在日程中心找到"团队日程"或"共享日程"入口
  2. 选择需要查看的团队或部门
  3. 系统将显示该团队成员共享的日程安排

10. 常见操作FAQ

10.1 登录相关

Q1：忘记密码怎么办？

A：请联系IT服务台（程文斐：0551-62201332 / 葛鹏飞：0551-62207154）进行密码重置。重置后会发送临时密码到您的手机或邮箱。

Q2：登录时提示"账号或密码错误"？

A：请检查以下几点：

  1. 确认输入的账号是否正确（工号或SSO账号）
  2. 确认密码是否输入正确，注意大小写
  3. 尝试使用"忘记密码"功能重置密码
  4. 如多次失败，请联系IT服务台

Q3：登录时提示"账号被锁定"？

A：连续输入错误密码5次后账号会被临时锁定，请等待30分钟后重试，或联系IT服务台解锁。

Q4：如何在多台设备上登录？

A：元信客户端支持在手机和电脑上同时登录。在新设备上安装元信后，使用同一账号密码登录即可。

10.2 消息相关

Q5：为什么收不到消息通知？

A：请检查以下设置：

  1. 确认元信客户端是否在前台运行
  2. 检查手机或电脑的通知权限是否开启
  3. 检查个人设置中的通知开关是否开启
  4. 确认网络连接是否正常

Q6：消息太多如何管理？

A：建议您：

  1. 使用消息分类筛选功能，按类型查看消息
  2. 及时将已读消息标记为已读
  3. 删除不需要保留的消息
  4. 设置合理的通知频率，避免过多打扰

Q7：为什么没有已读回执功能？

A：当前系统不提供已读追踪功能，即系统不会记录消息是否被阅读。这是系统设计的特性，不影响消息的正常接收和查看。

10.3 待办相关

Q8：待办事项处理后状态没有更新？

A：请检查以下几点：

  1. 确认是否点击了"提交"或"完成"按钮
  2. 刷新页面查看最新状态
  3. 如仍无更新，请联系系统管理员

Q9：如何查看已处理的待办？

A：在待办中心页面，点击"已办"标签，即可查看所有已处理的待办事项。

Q10：待办截止时间已过，还能处理吗？

A：可以处理。超期待办会显示"超期提醒"标识，但仍可正常处理。建议尽快处理超期待办，避免影响工作进度。

10.4 日程相关

Q11：如何取消已创建的日程？

A：进入日程详情页，点击"删除"按钮即可取消日程。如果日程有其他参与人，删除后会通知参与人。

Q12：日程提醒没有收到？

A：请检查以下设置：

  1. 确认个人设置中的日程提醒是否开启
  2. 确认提醒时间设置是否合理
  3. 检查通知权限是否开启
  4. 确认网络连接是否正常

10.5 系统相关

Q13：系统访问速度慢怎么办？

A：请尝试以下方法：

  1. 检查网络连接是否稳定
  2. 清除浏览器缓存（如通过浏览器访问）
  3. 关闭不必要的应用程序，释放系统资源
  4. 如持续缓慢，请联系IT服务台

Q14：如何反馈系统问题或建议？

A：您可以通过以下方式反馈：

  1. 在门户首页找到"意见反馈"入口提交
  2. 联系IT服务台（程文斐：0551-62201332 / 葛鹏飞：0551-62207154）
  3. 发送邮件至chengwenfei@gyzq.com.cn 或 gepengfei@gyzq.com.cn

Q15：系统维护时间是什么时候？

A：系统维护通知会提前通过消息中心和公告发布。一般维护安排在非工作时间（如周末或夜间），具体时间以通知为准。
