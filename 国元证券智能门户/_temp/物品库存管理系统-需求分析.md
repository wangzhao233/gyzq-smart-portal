## 一、项目概述

### 1.1 项目背景

为满足企业内部物品库存管理需求，基于七巧Plus低代码平台搭建一套物品库存管理系统。系统需覆盖物品信息管理、出入库操作、库存动态更新、数据报表分析等核心功能，支持多角色权限控制和审批流程。

### 1.2 建设目标

| 序号 | 目标 | 说明 |
|:--:|------|------|
| 1 | 物品信息管理 | 建立物品分类体系和物品档案，支持增删改查 |
| 2 | 出入库流程管控 | 通过审批流程规范出入库操作，自动更新库存 |
| 3 | 库存实时监控 | 聚合计算当前库存，安全库存预警 |
| 4 | 数据可视化 | 报表图表展示库存分布和使用情况 |
| 5 | 权限分级管理 | 管理员/仓库员/普通用户三级权限控制 |

---

## 二、用户角色

| 角色 | 使用场景 | 核心权限 |
|------|---------|---------|
| **管理员** | 系统管理、数据维护 | 全部权限（增删改查、审批、配置） |
| **仓库员** | 日常出入库操作 | 物品增删改查、出入库操作、库存管理 |
| **普通用户** | 物品领用、查看 | 仅查看物品信息和库存 |

## 三、功能需求

### 3.1 物品分类管理

建立物品分类体系，为物品提供分类维度。

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 分类名称 | 单行文本 | ✅ | 如"办公用品""电子设备" |
| 分类编码 | 单行文本 | ✅ | 如"BGYP""DZSB" |
| 排序号 | 数字 | ❌ | 控制显示顺序 |

### 3.2 物品信息管理

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 物品名称 | 单行文本 | ✅ | |
| 物品分类 | 外键选择（关联分类表） | ✅ | |
| 规格型号 | 单行文本 | ✅ | |
| 单位 | 下拉单选 | ✅ | 个/箱/台/套/件/支/本 |
| 初始库存 | 数字 | ✅ | 首次录入数量 |
| 当前库存 | 数字（聚合字段） | - | 自动计算 = 初始库存 + 总入库 - 总出库 - 总使用 |
| 安全库存 | 数字 | ❌ | 低库存预警线 |
| 物品图片 | 图片上传 | ❌ | |

**列表功能**：
- 支持按物品分类、库存状态（正常/预警/缺货）双维度筛选
- 支持导入导出Excel
- 列表中可发起出入库流程
- 支持新增、编辑、查看详情

### 3.3 出入库管理

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 物品 | 外键选择（关联物品表） | ✅ | |
| 操作类型 | 单选 | ✅ | 入库 / 出库 |
| 数量 | 数字 | ✅ | 最小值为1 |
| 操作人 | 人员单选 | ✅ | |
| 操作时间 | 日期时间 | ✅ | 默认当前时间 |
| 备注 | 多行文本 | ❌ | |

**核心逻辑**：
- 提交后自动更新物品表的当前库存字段
- 出库时校验库存是否充足（库存不足则阻止操作并提示）
- 库存低于安全库存时自动发送预警通知
- 列表页支持仅查看权限（普通用户）

### 3.4 物品使用记录

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 物品 | 外键选择（关联物品表） | ✅ | |
| 使用人 | 人员单选 | ✅ | |
| 使用数量 | 数字 | ✅ | 最小值为1 |
| 使用时间 | 日期时间 | ✅ | 默认当前时间 |
| 用途说明 | 多行文本 | ❌ | |

**核心逻辑**：提交后自动扣减物品库存

### 3.5 审批流程

物品出入库需经过审批流程：

```
申请人提交 → 部门负责人审批 → 指定审批人确认
```

- 支持处理人任意指定/转交
- 审批通过后自动执行库存更新脚本

### 3.6 首页仪表盘

| 组件 | 说明 |
|------|------|
| 物品总数 | 统计卡片，点击跳转物品列表 |
| 库存预警数 | 统计卡片，条件：当前库存 ≤ 安全库存 |
| 今日出入库 | 统计卡片，条件：操作时间=今天 |
| 使用排行榜 | Top10使用人排名，统计近30天使用次数 |

### 3.7 报表中心

| 组件 | 类型 | 说明 |
|------|------|------|
| 库存分布图 | 饼图 | 维度=物品分类，指标=物品计数 |
| 出入库趋势图 | 折线图 | 维度=操作时间（按月），指标=SUM(数量) |
| 报表卡片×4 | 统计卡片 | 物品总数/库存预警/本月入库/本月出库 |

### 3.8 聚合表

基于出入库记录和使用记录，聚合计算物品的实时库存：

| 配置项 | 说明 |
|--------|------|
| 主表 | 物品信息 |
| 数据源 | 出入库记录（关联物品）、使用记录（关联物品） |
| 入库总量 | SUM(数量) WHERE 操作类型=入库 |
| 出库总量 | SUM(数量) WHERE 操作类型=出库 |
| 使用总量 | SUM(使用数量) |
| 当前库存 | 初始库存 + 入库总量 - 出库总量 - 使用总量 |
| 校验规则 | 当前库存 ≥ 0 |

## 七、关键脚本逻辑

### 7.1 出入库提交后更新库存

```
1. 获取当前表单的"物品""操作类型""数量"字段值
2. 根据物品ID查询物品表中的当前库存
3. 如果是入库 → 当前库存 += 数量
4. 如果是出库 → 判断库存是否充足
   - 充足 → 当前库存 -= 数量
   - 不足 → 阻止操作，提示用户
5. 保存更新后的库存到物品表
6. 检查是否低于安全库存 → 低于则发送预警通知
```

### 7.2 使用记录提交后更新库存

```
1. 获取"物品""使用数量"
2. 查询物品当前库存
3. 判断库存是否充足 → 充足则扣减，不足则阻止
4. 保存更新
```

### 7.3 提交前校验

```
1. 校验数量 > 0
2. 出库时校验库存 >= 出库数量
3. 不满足条件则阻止提交并提示
```
