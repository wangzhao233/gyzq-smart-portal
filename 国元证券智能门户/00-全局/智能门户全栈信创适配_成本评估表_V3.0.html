说明

本报价单按系统维度组织，每个系统包含其所需的全套软件（应用软件 + 配套操作系统 + 数据库 + 中间件）。各投标厂商技术栈不同，配套基础软件选型可能有所差异，本方案基于道一信创 V3.0 选型（海光 CPU + 银河麒麟 V10 + OceanBase + 宝兰德中间件）。

📌 关于七巧低代码系统：七巧低代码与智能门户使用完全一致的技术栈（操作系统、数据库、中间件、搜索引擎、文档数据库均相同），部署在各自独立的服务器上。若七巧低代码同步进行信创适配，基础软件采购可统一规划，具体复用关系见第二章采购清单标注。

七、备注

  6. 七巧低代码与智能门户技术栈完全一致（同一信创方案），两套系统各自独立部署，基础软件采购节点数已合并计算
