# 国元证券二期 - 微盘文档权限颗粒度调研

## 一、目标与范围

本文档针对国元证券二期项目中微盘文档权限精细管控需求，评估以下两项核心需求的技术可行性并制定落地方案：

1. **标签批量授权**：按标签批量设置文件/空间权限（如"财务标签"自动授权财务部）
2. **门户角色打通**：门户角色体系与微盘权限体系联动（如门户管理员自动获得微盘管理权限）

---

## 二、企业微信微盘原生权限能力

### 2.1 原生权限层级

| 层级 | 权限项 | 说明 |
|------|--------|------|
| **空间级** | 空间管理员 | 可管理空间内所有文件及成员 |
| **空间级** | 空间成员 | 支持按个人/部门设置可见范围 |
| **文件级** | 可编辑 | 对指定文件的编辑权限 |
| **文件级** | 可查看 | 对指定文件的只读权限 |
| **分享级** | 企业内分享 | 仅限企业内成员访问 |
| **分享级** | 指定成员分享 | 仅指定人员可访问 |
| **分享级** | 链接分享 | 支持密码和有效期设置 |

### 2.2 原生能力的局限性

| 局限项 | 说明 | 影响 |
|--------|------|------|
| 不支持标签维度授权 | 原生只支持按个人/部门设置，无标签维度 | 无法实现"财务标签"一键授权 |
| 不支持角色联动 | 微盘与门户角色体系相互独立 | 权限变更需在两个系统分别操作 |
| 批量操作能力弱 | 原生无批量权限设置界面 | 大量文件授权效率低 |

---

## 三、企业微信微盘 API 能力

### 3.1 可用 API 能力梳理

| API 类别 | 接口能力 | 用途 |
|---------|---------|------|
| **空间管理** | 新增/删除/查询空间 | 空间的增删查 |
| **空间成员** | 添加/删除/查询成员，设置管理员 | 批量管理空间成员与权限 |
| **文件管理** | 上传/下载/删除/移动/查询文件 | 文件基础操作 |
| **文件权限** | 设置文件权限（可编辑/可查看）、设置指定成员权限 | 文件级权限控制 |
| **权限查询** | 查询文件/空间的当前权限列表 | 权限现状查询 |

### 3.2 API 能力对需求的支撑度

| 需求项 | API 支撑情况 | 实现路径 |
|--------|:-----------:|---------|
| 按标签批量设置文件权限 | ✅ 可通过二次开发实现 | 从门户标签体系获取成员列表 → 批量调用文件权限 API |
| 门户管理员自动获得微盘管理权限 | ✅ 可通过二次开发实现 | 门户角色变更时触发回调 → 调用空间成员管理 API |
| 权限变更实时同步 | ⚠️ 需设计同步机制 | 异步队列+定时补偿，避免 API 限频 |

### 4.2 需求一：标签批量授权

**业务目标**：为某标签下的全部成员批量授予指定文件/空间的权限，如"财务标签"成员自动获得财务相关文件的查看权限。

**实现逻辑**：

```
① 管理员在门户后台配置标签授权规则
   └── 规则示例：[财务标签] → [财务空间/文件夹] → [可查看]

② 触发条件（任一满足即触发同步）
   ├── 管理员手动触发
   ├── 标签成员新增/移除
   └── 授权规则变更

③ 权限同步引擎执行
   ├── 读取标签下全部成员列表
   ├── 批量调用微盘 API 设置权限
   └── 写入执行日志，异常时告警
```

**功能模块**：

| 功能 | 说明 |
|------|------|
| 标签授权规则配置 | 支持配置"标签 → 文件/空间 → 权限类型"的映射规则 |
| 批量授权执行 | 按规则批量调用 API，支持手动触发和自动触发 |
| 授权结果查看 | 查看每次授权任务的执行状态和结果明细 |
| 成员变更联动 | 标签成员新增时自动追加权限，移除时自动回收 |

### 4.3 需求二：门户角色体系打通

**业务目标**：门户角色与微盘权限等级建立映射关系，角色变更时自动同步至微盘，无需在两个系统分别操作。

**角色映射规则示例**：

| 门户角色 | 微盘权限等级 | 说明 |
|---------|:----------:|------|
| 超级管理员 | 空间管理员 | 最高权限 |
| 部门管理员 | 本部门空间管理员 | 仅管理所属部门空间 |
| 普通员工 | 空间成员（可查看） | 默认只读 |
| 自定义角色 | 按规则配置 | 灵活配置 |

**实现逻辑**：

```
① 管理员在门户后台配置角色-微盘权限映射表

② 触发条件（任一满足即触发同步）
   ├── 新成员入职（分配门户角色时自动同步微盘权限）
   ├── 成员角色变更
   └── 成员离职（自动回收微盘权限）

③ 权限同步引擎执行
   ├── 查询变更成员的当前门户角色
   ├── 按映射规则调用微盘 API 更新权限
   └── 记录同步日志
```

**功能模块**：

| 功能 | 说明 |
|------|------|
| 角色权限映射配置 | 配置门户角色与微盘权限等级的对应关系 |
| 全量同步 | 一键将现有全部成员的门户角色同步至微盘 |
| 增量同步 | 成员角色变更时实时触发同步 |
| 离职权限回收 | 成员离职时自动回收全部微盘权限 |

## 七、风险评估

| 风险等级 | 风险项 | 风险描述 | 应对措施 |
|:--------:|-------|---------|---------|
| 高 | 微盘 API 调用频率限制 | 企业微信对 API 调用有频率限制，批量操作时可能触发限频 | 设计异步队列，分批次执行；实现失败重试与补偿机制 |
| 中 | 初始化全量同步数据量大 | 现有成员/文件数量多时，全量初始化耗时较长 | 初始化阶段安排在业务低峰期执行，预估耗时后告知客户 |
| 中 | 门户标签与微盘权限的一致性 | 标签成员变更频繁时，权限同步可能存在短暂延迟 | 同步延迟控制在5分钟以内，关键场景支持手动即时同步 |
| 低 | 微盘 API 版本变更 | 企业微信 API 更新可能影响接口 | 基于官方文档开发，关注 API 变更通知 |
