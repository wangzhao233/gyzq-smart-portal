## 一、部署前检查

### 1.1 服务器环境

```bash
# SSH连接
ssh root@10.0.63.11

# 检查Java版本（需JDK 8+）
java -version
javac -version

# 如无Java，安装：
yum install java-1.8.0-openjdk-devel -y

# 检查Nginx
nginx -v
systemctl status nginx

# 检查端口8899是否被占用
netstat -tlnp | grep 8899
```

### 1.2 网络连通性

```bash
# 从服务器访问OA外网
curl -I http://home.oa.gyzq.com

# 检查DNS解析
nslookup home.oa.gyzq.com
```

### 1.3 OA账号

- 确认OA服务账号和密码
- 确认认证方式（cookie_form 或 ntlm）

### 1.4 本地预验证（可选）

在部署到服务器前，可在本地用 `--test-mode` 验证JSON格式：

```bash
# 测试模式（无需OA账号，返回模拟数据）
java -cp . src.OaProxyServer --test-mode oa-proxy.properties

# 测试健康检查
curl http://localhost:8899/health

# 测试新闻接口
curl -X POST http://localhost:8899/api/news -d "typeId=gsdt&maxCount=3&currentPage=1"
```

## 二、部署步骤

### 2.1 上传文件

将以下文件传到服务器 `/tmp/oa-news-proxy-java/`：

```
oa-news-proxy-java/
├── build.sh
├── deploy.sh
├── verify.sh
├── oa-proxy.properties
├── nginx/
│   └── oa-news-proxy.conf
└── src/
    └── OaProxyServer.java
```

```bash
# 在本地执行（假设用scp）
scp -r _deploy/oa-news-proxy-java/ root@10.0.63.11:/tmp/
```

### 2.2 配置OA账号

```bash
# 在服务器上
vi /tmp/oa-news-proxy-java/oa-proxy.properties
```

修改：
```properties
oa.username=实际OA账号
oa.password=实际密码
```

### 2.3 执行部署

```bash
cd /tmp/oa-news-proxy-java
chmod +x deploy.sh
sudo bash deploy.sh
```

部署脚本会自动：
1. 编译Java源码
2. 打包JAR
3. 部署到 `/opt/oa-news-proxy/`
4. 配置Nginx
5. 注册systemd服务

### 2.4 启动服务

```bash
# 启动
systemctl start oa-proxy
systemctl enable oa-proxy

# 检查状态
systemctl status oa-proxy
```

## 四、故障排查

### 4.1 服务无法启动

```bash
# 查看日志
journalctl -u oa-proxy -n 50

# 常见原因：
# 1. Java版本过低
# 2. 配置文件路径错误
# 3. 端口被占用
```

### 4.2 登录失败

```bash
# 检查配置
cat /opt/oa-news-proxy/oa-proxy.properties

# 尝试切换认证方式
# oa.auth.type=cookie_form → oa.auth.type=ntlm

# 重启服务
systemctl restart oa-proxy
```

### 4.3 返回401

```bash
# Cookie过期或账号密码错误
# 1. 检查账号密码
# 2. 重启服务重新登录
systemctl restart oa-proxy

# 查看日志确认登录状态
journalctl -u oa-proxy -f
```

### 4.4 返回502

```bash
# 代理服务未启动
systemctl status oa-proxy
systemctl start oa-proxy

# 检查端口
netstat -tlnp | grep 8899
```

### 4.5 返回504

```bash
# OA响应超时
# 检查网络连通性
curl -I http://home.oa.gyzq.com

# 调整超时配置
vi /opt/oa-news-proxy/oa-proxy.properties
# session.request.timeout.seconds=30

systemctl restart oa-proxy
```

## 六、回滚方案

如果部署失败需要回滚：

```bash
# 停止服务
systemctl stop oa-proxy
systemctl disable oa-proxy

# 删除文件
rm -rf /opt/oa-news-proxy/
rm /etc/nginx/conf.d/oa-news-proxy.conf
rm /etc/systemd/system/oa-proxy.service

# 重载Nginx
nginx -t && nginx -s reload

# 清理systemd
systemctl daemon-reload
```
