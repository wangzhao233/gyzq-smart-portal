# 节点 20：登录

## 你在哪里

浏览器已打开，需要登录七巧平台。

## 本节点产出

- 用户已成功登录（`window.$ai.init()` 返回 `undefined`）

## 核心规则：必须执行 window.$ai.init()

登录成功后，**无论你是否已经确认用户登录了，都必须执行一次 `window.$ai.init()`**：

- 用于验证登录态（返回 `undefined` 表示成功）
- 用于初始化 `$ai` API，确保后续所有 `window.$ai.findDom()`、`window.$ai.fillingForm()` 可用
- **即使你觉得 `$ai` 可能不可用，也要执行 `window.$ai.init()`**，不要跳过
- **全流程中只要发现 `$ai` 不可用（报错、返回异常），先执行 `window.$ai.init()` 再重试**（见 GR-01-6）

## 可执行操作

| # | 操作名 | 前置条件 | 执行内容 | 下一节点 |
|---|--------|---------|---------|---------|
| 1 | 打开平台 | 浏览器已打开 | `bsk navigate` 到 `{PLATFORM_DOMAIN}/qiqiao2/runtime/` | 留在本节点 |
| 2 | 手动登录 | 页面已打开 | 提示用户手动登录 | 用户确认后继续 |
| 3 | 初始化并验证 | 用户确认登录完成 | 执行 `window.$ai.init()` | → 节点 30 / 重试 |

### 操作 1：打开平台

```
bsk navigate("{PLATFORM_DOMAIN}/qiqiao2/runtime/")
```

页面加载后，**确认页面确实打开了**（`bsk snapshot` 检查页面是否有内容）。

### 操作 2：手动登录

打开平台后若未自动登录，提示用户：

> 请在浏览器中手动登录。登录成功后告诉我。

### 操作 3：初始化并验证（必做）

用户确认登录完成后，**无论之前是否已经调过 `window.$ai.init()`，都必须再次执行**：

```
bsk evaluate → window.$ai.init()
```

| 结果 | 含义 | 处理 |
|------|------|------|
| 返回 `undefined` | ✅ 初始化成功，`$ai` 可用 | → 节点 30（首页） |
| 报错 / `$ai` 不存在 | ❌ 未登录或页面未加载 | 刷新页面后重试 `init()`；仍失败则询问用户 |

> 即使之前已用 `bsk evaluate` 确认过页面状态，**也必须执行 `window.$ai.init()`**。这是确保后续 `window.$ai.findDom`、`window.$ai.fillingForm` 等 API 可用的必要步骤，不可跳过。

## 操作失败处理

| 失败场景 | 处理方式 | 回退节点 |
|----------|---------|---------|
| `window.$ai` 不存在 | 刷新页面 → 重新 `window.$ai.init()`；仍失败则确认用户是否在七巧Plus平台页面 | 留在本节点 |
| `window.$ai.init()` 报错 | 刷新页面后重试；仍失败则询问用户 | 留在本节点 |
