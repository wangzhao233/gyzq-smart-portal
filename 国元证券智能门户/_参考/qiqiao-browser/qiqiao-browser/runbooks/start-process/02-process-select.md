# 发起流程 02：流程选择

## 你在哪里

已在流程选择弹窗中输入关键词并完成搜索，看到搜索结果列表。你可以选择目标流程，也可以重新搜索或关闭弹窗。

## 本节点产出

- 已点击目标流程，打开发起流程表单弹窗

## 可执行操作

| # | 操作名 | 前置条件 | 执行内容 | 下一节点 |
|---|--------|---------|---------|---------|
| 1 | 选择流程 | 搜索结果已展示 | 从列表中选择目标流程并点击 | → `03-process-form.md` |
| 2 | 重新搜索 | 未找到目标流程或想换关键词 | 回到搜索步骤 | → `01-process-search.md` |
| 3 | 返回首页 | 用户想取消发起流程 | 关闭弹窗 | → `../common/30-home.md`（节点 30） |

### 操作 1 详细：选择流程

搜索结果的元数据格式示例：

```json
{ id: '69d5bd5dbe4e263f98314e61', name: '简历', desc: '应用：【演示】AI演示下的流程：简历，点击发起流程，打开弹窗', action: 'click', type: null }
```

获取搜索结果并按 GR-03 规则处理：

```js
const refs = window.$ai.findDom('流程名称关键词');
const metadatas = refs.map(ref => window.$ai.getMetadata(ref));
```

| 搜索结果 | 处理方式 |
|----------|---------|
| **唯一结果** | 直接 `refs[0].click()` |
| **多个结果** | 展示 `name`、`desc`、`id` 让用户确认选择，**禁止**默认选第一个 |
| **无结果** | 询问用户是否换关键词重新搜索，引导进入操作 2 |

> ⚠️ **GR-03**：多个结果时必须让用户确认，**禁止**自行探索或猜测。

### 操作 2 详细：重新搜索

回到 `01-process-search.md` 重新输入关键词搜索。

### 操作 3 详细：返回首页

关闭弹窗（按 Esc 或点击弹窗关闭按钮），返回首页。

## 操作失败处理

| 失败场景 | 处理方式 | 回退节点 |
|----------|---------|---------|
| 搜索无结果 | 询问用户是否换关键词 | → `01-process-search.md` |
| 搜索多个结果用户无法区分 | 展示更多元数据信息辅助判断 | 留在本节点 |
| 点击流程后无响应 | 用 `bsk snapshot` 检查弹窗状态 | 留在本节点 |

## 下一节点

操作 1 成功 → **`03-process-form.md`（发起流程表单弹窗）**
操作 2 → **`01-process-search.md`（流程搜索）**
操作 3 → **`../common/30-home.md`（节点 30：首页）**
