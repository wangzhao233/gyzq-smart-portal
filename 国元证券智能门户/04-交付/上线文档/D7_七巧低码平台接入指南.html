2. 七巧平台概述

2.1 平台简介与核心能力

七巧Plus是低代码应用搭建平台，提供6大组件能力，旨在帮助业务人员和开发者快速构建企业级应用，无需编写大量代码即可实现业务流程数字化。

核心能力包括：

  1. 拖拽式页面设计： 可视化拖拽组件，快速构建用户界面
  2. 数据集成： 支持多种数据源连接和数据流设计
  3. BI报表： 丰富的图表类型和数据分析功能
  4. 工作流编排： 灵活的审批流程和业务流程配置
  5. 系统集成： 与现有系统无缝对接
  6. 低/高代码扩展： 支持低代码配置和高代码开发扩展

2.2 三种IT建设模式

七巧平台支持三种IT建设模式，满足不同复杂度的业务需求：

  1. 零代码模式：
    - 适用于Excel电子化、简单表单收集
    - 无需任何编码知识
    - 快速实现业务数据采集和简单流程
  1. 低代码模式：
    - 适用于非标准流程、业务规则配置
    - 通过可视化配置实现复杂业务逻辑
    - 适合大多数企业应用场景
  1. 高代码模式：
    - 适用于复杂集成、定制化开发
    - 支持JavaScript、SQL等代码扩展
    - 满足高度定制化需求

2.3 五种页面设计器

七巧平台提供五种页面设计器，覆盖不同应用场景：

  1. 普通表单设计器：
    - 用于数据收集和信息录入
    - 支持多种表单组件
    - 适用于简单数据采集场景
  1. 流程表单设计器：
    - 用于需要审批流程的业务
    - 集成工作流引擎
    - 支持复杂的审批逻辑
  1. 报表设计器：
    - 用于数据展示和分析
    - 支持多种图表类型
    - 提供数据钻取和联动功能
  1. 基础页面设计器：
    - 用于构建自定义页面
    - 支持静态内容和简单交互
    - 适用于信息展示页面
  1. 高级页面设计器：
    - 用于复杂交互和定制化界面
    - 支持JavaScript代码扩展
    - 满足高度定制化需求

3. 应用管理

3.1 创建应用

创建应用是使用七巧平台的第一步，支持三种创建方式：

创建步骤：

  1. 登录七巧平台，进入应用管理页面
  2. 点击"新建应用"按钮
  3. 选择创建方式：
    - 空白应用： 从零开始创建
    - 从模板： 选择现有模板快速创建
    - 导入： 导入已有的应用配置
  4. 填写应用基本信息：
    - 应用名称
    - 应用描述
    - 应用分类
    - 应用图标
  5. 点击"创建"完成应用创建

3.2 应用分组与管理

为了便于管理，可以对应用进行分组：

应用分组操作：

  1. 在应用管理页面，点击"分组管理"
  2. 创建新分组或选择现有分组
  3. 将应用拖拽到对应分组
  4. 支持最多30个应用分组

应用管理功能：

  • 应用搜索： 通过名称快速查找应用
  • 应用排序： 按名称、创建时间等排序
  • 应用状态： 查看应用发布状态
  • 应用克隆： 复制现有应用配置

3.3 应用发布流程

应用开发完成后，需要经过发布流程才能正式使用：

应用发布步骤：

  1. 权限设置：
    - 配置应用访问权限
    - 设置角色和用户权限
    - 配置数据权限
  1. 发布设置：
    - 设置应用版本号
    - 配置发布范围
    - 设置应用可见性
  1. 流程发布：
    - 提交发布申请
    - 管理员审核
    - 正式发布上线

注意事项：

  • 应用发布前需取消发布状态才能删除
  • 发布后修改需创建新版本
  • 支持版本回滚功能

3.4 应用导入导出

支持应用配置的导入导出，便于应用迁移和备份：

导出应用：

  1. 选择要导出的应用
  2. 点击"导出"按钮
  3. 选择导出内容（表单、流程、报表等）
  4. 下载导出文件

导入应用：

  1. 点击"导入"按钮
  2. 选择导入文件
  3. 配置导入选项
  4. 完成应用导入

应用场景：

  • 应用环境迁移
  • 应用备份恢复
  • 应用模板分享

4. 表单设计入门

4.1 常用组件介绍

七巧平台提供15种常用表单组件，满足各种数据收集需求：

基础输入组件：

  1. 单行文本： 用于输入简短文本信息
  2. 多行文本： 用于输入较长文本内容
  3. 数字： 用于输入数值数据
  4. 单选： 从多个选项中选择一个
  5. 多选： 从多个选项中选择多个
  6. 日期： 选择日期和时间

选择组件：

  1. 人员选择： 从组织架构中选择人员
  2. 部门选择： 从组织架构中选择部门
  3. 外键选择： 关联其他表单数据

文件组件：

  1. 文件上传： 上传附件文件
  2. 图片上传： 上传图片文件

特殊组件：

  1. 子表单： 嵌套表单数据
  2. 生成编码： 自动生成唯一编码
  3. 富文本： 富文本编辑器
  4. 描述说明： 添加说明文字

4.2 表单属性配置

表单属性配置决定了表单的行为和外观：

表单类型设置：

  • E-R类型： 设置表单的数据模型类型

  • 提交校验： 设置表单提交时的验证规则
  • 唯一校验： 设置字段的唯一性约束

高级属性配置：

  • 评论功能： 启用表单评论功能
  • 修改记录： 记录表单修改历史
  • 外部单： 支持外部数据接入
  • 索引设置： 优化查询性能的索引配置

配置步骤：

  1. 打开表单设计器
  2. 选择表单属性面板
  3. 配置各项属性参数
  4. 保存配置并测试

4.3 子表关联功能

子表关联功能支持复杂的数据关系设计：

关联类型：

  1. 子表单： 在表单内嵌套子表数据
  2. 子表关联： 关联其他表单的子表数据
  3. 多表关联： 同时关联多个表单数据
  4. 关联查询： 根据条件查询关联数据

配置步骤：

  1. 在表单设计器中添加关联组件
  2. 选择关联的表单和字段
  3. 配置关联条件和显示字段
  4. 设置数据同步规则
  5. 测试关联功能

应用场景：

  • 订单与订单明细关联
  • 员工与部门信息关联
  • 项目与任务关联

5. 流程设计入门

5.1 节点类型

七巧平台支持四种节点类型，构建完整的业务流程：

节点类型说明：

  1. 人工任务节点：
    - 需要人工处理的审批或办理节点
    - 支持多种操作（审批、驳回、加签等）
    - 可配置处理人和处理规则
  1. 系统任务节点：
    - 系统自动执行的任务
    - 支持调用外部接口
    - 执行数据操作和业务逻辑
  1. 子流程节点：
    - 调用其他流程作为子流程
    - 支持流程复用
    - 实现复杂业务流程拆分
  1. 网关节点：
    - 流程分支和合并控制
    - 支持条件判断和并行处理
    - 控制流程走向

5.2 网关类型

网关类型决定了流程的分支和合并逻辑：

网关类型说明：

  1. 排他网关：
    - 根据条件选择唯一分支
    - 只能选择一个满足条件的分支
    - 适用于互斥的业务规则
  1. 并行网关：
    - 同时执行所有分支
    - 等待所有分支完成后继续
    - 适用于并行处理场景
  1. 包容网关：
    - 根据条件选择多个分支
    - 可以同时执行多个分支
    - 等待所有激活分支完成

网关配置步骤：

  1. 在流程设计器中添加网关节点
  2. 选择网关类型
  3. 配置分支条件
  4. 连接后续节点
  5. 测试网关逻辑

5.3 审批规则

审批规则定义了节点的处理方式：

审批规则类型：

  1. 会签（100%提交）：
    - 所有处理人都需要审批
    - 全部同意才能通过
    - 适用于重要决策审批
  1. 或签（单人审批）：
    - 任意一人审批即可
    - 提高审批效率
    - 适用于常规审批
  1. 分支流程：
    - 根据条件选择不同审批路径
    - 支持多级分支
    - 适用于复杂审批逻辑

配置步骤：

  1. 选择审批节点
  2. 配置审批规则类型
  3. 设置处理人范围
  4. 配置审批条件
  5. 设置超时提醒和处理

5.4 处理人设置

处理人设置决定了谁来处理流程节点：

处理人范围：

  1. 指定人员： 直接指定具体处理人
  2. 部门人员： 指定部门内的人员
  3. 角色人员： 指定角色对应的人员
  4. 发起人自选： 由发起人选择处理人
  5. 表单字段： 根据表单字段值确定处理人
  6. 上级领导： 发起人的上级领导
  7. 部门负责人： 发起人所在部门负责人
  8. 自定义规则： 自定义处理人选择规则

配置步骤：

  1. 选择处理人节点
  2. 配置处理人范围
  3. 设置处理人条件
  4. 配置多人处理规则
  5. 测试处理人分配

5.5 节点操作

节点操作定义了处理人在节点上可以执行的操作：

常用节点操作：

  • 办理： 处理节点任务
  • 驳回： 驳回到上一节点
  • 加签： 添加其他处理人
  • 暂存： 保存当前处理状态
  • 撤回： 撤回已提交的流程
  • 催办： 催促处理人处理
  • 撤销： 撤销整个流程
  • 委托： 委托他人处理
  • 抄送： 抄送通知相关人员
  • 终止： 终止流程
  • 评论： 添加评论信息
  • 打印： 打印流程表单
  • 标记： 标记流程状态

5.6 高级功能

流程设计支持多种高级功能：

超时提醒：

  • 设置节点处理时限
  • 超时自动提醒处理人
  • 支持多级提醒

超时处理：

  • 超时自动提交
  • 超时自动驳回
  • 超时自动转交

自动提交：

  • 满足条件自动提交
  • 减少人工干预
  • 提高流程效率

流程版本：

  • 支持流程版本管理
  • 版本对比和回滚
  • 灰度发布

图表类型说明：

  1. 汇总表： 展示数据汇总信息
  2. 折线图： 展示数据趋势变化
  3. 柱状图： 展示数据对比
  4. 条形图： 水平展示数据对比

  6. 雷达图： 展示多维度数据对比
  7. 饼状图： 展示数据占比关系
  8. 指标图： 展示关键指标数值
  9. 明细表： 展示详细数据列表

  • 待办提醒集成
  • 待办统计集成

8.6 SSO单点登录

SSO单点登录支持三种登录模式：

登录模式：

  1. 普通外部登录： 标准外部用户登录
  2. OAuth2.0登录： 支持OAuth2.0协议
  3. Azure AD登录： 支持Azure Active Directory

配置步骤：

  1. 进入SSO配置页面
  2. 选择登录模式
  3. 配置认证参数
  4. 配置用户映射
  5. 测试登录功能
  6. 启用SSO登录

配置参数：

  • 认证服务器地址
  • 客户端ID和密钥
  • 回调地址
  • 用户信息映射
