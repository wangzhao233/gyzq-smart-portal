## 1. 管理员角色与权限说明

### 1.1 角色定义

国元证券智能门户系统采用分层授权的管理模式，根据管理范围和职责不同，系统预设以下管理员角色：

| 角色名称 | 管理范围 | 主要职责 |
|---------|---------|---------|
| **超级管理员** | 全系统 | 系统全局配置、所有用户和部门管理、权限分配、系统维护 |
| **总部管理员** | 总部及各部门 | 管理总部各部门用户、分配部门管理员权限、维护总部级应用 |
| **子公司管理员** | 所辖子公司 | 管理子公司用户、分配子公司内部门管理员、维护子公司级应用 |
| **分公司管理员** | 所辖分公司 | 管理分公司用户、分配分公司内部门管理员、维护分公司级应用 |
| **部门管理员** | 本部门 | 管理本部门用户、维护部门信息、分配部门内应用权限 |
| **内容管理员** | 指定内容模块 | 负责新闻公告、消息中心等内容的发布与管理 |
| **应用管理员** | 指定应用 | 负责特定应用的配置、维护与权限管理 |

### 1.2 权限层级说明

系统权限采用"集团→总部→子公司→分公司→部门"的五级管理体系，具体权限继承关系如下：

```
集团级（超级管理员）
  ├── 总部级（总部管理员）
  │     ├── 部门级（部门管理员）
  │     └── ...
  ├── 子公司级（子公司管理员）
  │     ├── 分公司级（分公司管理员）
  │     │     ├── 营业部级（营业部管理员）
  │     │     └── ...
  │     └── ...
  └── ...
```

### 1.3 角色分配原则

1. **最小权限原则**：仅授予完成工作所必需的最小权限集合
2. **职责分离原则**：关键操作需多人协作，避免单一角色拥有过大权限
3. **定期审查原则**：每季度对管理员权限进行审查，及时调整异常权限
4. **权限继承限制**：下级管理员不得授予超过上级管理员的权限范围

## 2. 后台管理入口

### 2.1 访问方式

**管理后台访问地址**：

| 访问方式 | 地址 | 说明 |
|---------|------|------|
| **PC端Web访问** | https://admin.portal.oa.gyzq.com | 推荐使用Chrome 90+或Edge 90+浏览器 |
| **PC端快捷入口** | 左上角任务头像 → 快捷入口 → 登录管理台 | 通过元信PC客户端快速跳转 |
| **元信客户端内访问** | 工作台 → 管理后台 | 需安装国元元信客户端 |
| **移动端访问** | https://admin.portal.oa.gyzq.com/mobile | 支持iOS 14+/Android 10+ |

**网络要求**：
- 内网访问：无需特殊配置
- 外网访问：需通过VPN接入公司内网

### 2.2 登录流程

> **说明**：仅拥有管理员权限的用户才能登录管理后台。如需开通管理员权限，请联系超级管理员进行配置。

**方式一：网页扫码登录（推荐）**

**步骤1：打开管理后台页面**

在浏览器地址栏输入管理后台地址，按回车键打开登录页面。

**步骤2：扫码认证**

使用已登录的移动端元信客户端，扫描页面显示的二维码完成身份认证。

**步骤3：进入管理后台**

扫码确认后，系统自动跳转至管理后台首页。

**方式二：账号密码登录**

**步骤1：打开管理后台页面**

在浏览器地址栏输入管理后台地址，按回车键打开登录页面。

**步骤2：输入登录凭据**

在登录页面输入以下信息：
- **用户名**：管理员工号（如：GY00001）
- **密码**：初始密码为身份证后6位（首次登录需修改）

**步骤3：完成身份验证**

根据系统配置，可能需要完成以下验证方式之一：
- **短信验证码**：向绑定的手机号发送验证码
- **企业微信扫码**：使用元信客户端扫描二维码
- **动态令牌**：输入动态令牌生成的6位数字

**步骤4：进入管理后台**

验证通过后，系统自动跳转至管理后台首页。

### 2.3 安全登录建议

1. **密码复杂度要求**：
   - 长度不少于8位
   - 包含大小写字母、数字和特殊字符
   - 不得使用连续或重复字符
   - 不得与用户名相同

2. **登录安全设置**：
   - 连续5次密码错误将锁定账户30分钟
   - 建议开启登录IP白名单限制
   - 敏感操作需二次验证

3. **会话管理**：
   - 默认会话超时时间：30分钟
   - 可在系统设置中调整超时时间
   - 建议在公共计算机上使用后及时退出

## 3. 用户管理

### 3.1 新增用户

**操作路径**：用户管理 → 用户列表 → 新增用户

**操作步骤**：

**步骤1：进入用户管理页面**

在左侧导航栏选择"用户管理"，点击"用户列表"。

**步骤2：点击新增用户按钮**

在用户列表页面右上角，点击"新增用户"按钮。

**步骤3：填写用户信息**

在新增用户表单中填写以下信息：

| 字段名称 | 填写说明 | 是否必填 |
|---------|---------|---------|
| 工号 | 员工工号，系统唯一标识 | 是 |
| 姓名 | 员工真实姓名 | 是 |
| 所属部门 | 选择员工所属部门 | 是 |
| 手机号 | 员工手机号码，用于接收验证码 | 是 |
| 邮箱 | 员工企业邮箱 | 否 |
| 职位 | 员工职位名称 | 否 |
| 入职日期 | 员工入职日期 | 否 |
| 账户状态 | 默认为"启用" | 是 |

**步骤4：设置初始密码**

系统默认设置初始密码为身份证后6位，并勾选"首次登录强制修改密码"。

**步骤5：分配角色权限**

在"角色分配"区域，勾选该用户需要的角色权限。

**步骤6：保存并通知**

点击"保存"按钮，系统自动发送欢迎邮件和短信通知。

### 3.2 编辑用户信息

**操作路径**：用户管理 → 用户列表 → 选择用户 → 编辑

**操作步骤**：

**步骤1：查找目标用户**

在用户列表页面，通过以下方式查找用户：
- 搜索框输入工号或姓名
- 按部门筛选
- 按状态筛选（启用/禁用）

**步骤2：进入编辑页面**

在用户列表中找到目标用户，点击操作列的"编辑"按钮。

**步骤3：修改用户信息**

在编辑页面修改需要更新的信息，可修改的字段包括：
- 姓名、手机号、邮箱等基本信息
- 所属部门、职位等组织信息
- 角色权限分配

**步骤4：保存修改**

点击"保存"按钮，系统记录修改日志。

### 3.3 禁用/启用用户

**操作路径**：用户管理 → 用户列表 → 选择用户 → 禁用/启用

**操作步骤**：

**步骤1：查找目标用户**

在用户列表页面，通过搜索或筛选找到目标用户。

**步骤2：执行状态变更**

- **禁用用户**：点击操作列的"禁用"按钮，系统弹出确认对话框，确认后用户状态变更为"禁用"
- **启用用户**：点击操作列的"启用"按钮，系统弹出确认对话框，确认后用户状态变更为"启用"

**步骤3：状态变更影响**

| 状态 | 影响范围 |
|------|---------|
| 禁用 | 用户无法登录系统，已分配的应用权限保留但不可用 |
| 启用 | 用户恢复登录权限，原有应用权限自动恢复 |

### 3.4 批量导入用户

**操作路径**：用户管理 → 用户列表 → 批量导入

**操作步骤**：

**步骤1：下载导入模板**

在用户列表页面，点击"批量导入"按钮，选择"下载模板"。

**步骤2：填写用户信息**

打开下载的Excel模板，按照以下格式填写用户信息：

| 工号 | 姓名 | 所属部门 | 手机号 | 邮箱 | 职位 | 入职日期 |
|------|------|---------|--------|------|------|---------|
| GY00001 | 张三 | 总部办公室 | 13800138000 | zhangsan@gyzq.com | 办公室主任 | 2024-01-15 |
| GY00002 | 李四 | 信息技术部 | 13900139000 | lisi@gyzq.com | 系统工程师 | 2024-02-20 |

**步骤3：上传文件**

在批量导入页面，点击"选择文件"按钮，选择填写好的Excel文件。

**步骤4：数据校验**

系统自动校验数据格式和完整性，校验结果包括：
- 校验通过的数据条数
- 校验失败的数据条数及失败原因

**步骤5：执行导入**

确认校验无误后，点击"开始导入"按钮，系统逐条导入用户数据。

**步骤6：导入结果查看**

导入完成后，系统显示导入结果：
- 成功导入条数
- 失败条数及失败原因
- 生成导入日志供下载

**操作步骤**：

**步骤1：查看组织架构树**

在部门管理页面，系统以树状结构展示完整的组织架构：
```
国元证券股份有限公司（集团）
├── 总部
│   ├── 办公室
│   ├── 人力资源部

│   ├── 信息技术部
```

**步骤2：展开/折叠节点**

**步骤3：查看部门详情**

### 4.2 新增部门

**操作路径**：部门管理 → 组织架构 → 选择上级部门 → 新增子部门

**操作步骤**：

**步骤1：选择上级部门**

在组织架构树中，点击要新增子部门的上级部门节点。

**步骤2：点击新增按钮**

在部门详情页面，点击"新增子部门"按钮。

**步骤3：填写部门信息**

在新增部门表单中填写以下信息：

| 字段名称 | 填写说明 | 是否必填 |
|---------|---------|---------|
| 部门名称 | 部门全称 | 是 |
| 部门编码 | 系统自动生成，可手动修改 | 是 |
| 上级部门 | 自动填充当前选择的部门 | 是 |
| 部门类型 | 选择部门类型（总部/子公司/分公司/营业部/部门） | 是 |
| 部门管理员 | 选择该部门的管理员 | 否 |
| 排序号 | 同级部门中的显示顺序 | 否 |
| 备注 | 部门描述信息 | 否 |

**步骤4：保存并生效**

点击"保存"按钮，系统自动更新组织架构树。

### 4.3 编辑部门

**操作路径**：部门管理 → 组织架构 → 选择部门 → 编辑

**操作步骤**：

**步骤1：选择目标部门**

在组织架构树中，点击要编辑的部门节点。

**步骤2：进入编辑模式**

在部门详情页面，点击"编辑"按钮。

**步骤3：修改部门信息**

在编辑页面修改需要更新的信息，可修改的字段包括：
- 部门名称、部门类型
- 部门管理员
- 排序号、备注

**步骤4：保存修改**

点击"保存"按钮，系统记录修改日志。

### 4.4 删除部门

**操作路径**：部门管理 → 组织架构 → 选择部门 → 删除

**操作步骤**：

**步骤1：选择目标部门**

在组织架构树中，点击要删除的部门节点。

**步骤2：检查删除条件**

系统检查以下删除条件：
- 该部门下是否有子部门
- 该部门下是否有用户
- 该部门是否为系统必需部门

**步骤3：执行删除**

- **满足删除条件**：点击"删除"按钮，系统弹出确认对话框，确认后删除该部门
- **不满足删除条件**：系统提示无法删除的原因，需先处理子部门或用户

**步骤4：删除后处理**

删除部门后，系统自动：
- 将该部门下的用户移至上级部门
- 更新组织架构树
- 记录删除操作日志

### 4.5 部门层级管理

**操作路径**：部门管理 → 层级设置

**操作步骤**：

**步骤1：查看当前层级设置**

在层级设置页面，显示当前组织架构的层级信息：
- 最大层级深度
- 各层级名称
- 层级编码规则

**步骤2：调整层级设置**

根据组织架构调整需求，可以：
- 新增层级（如：新增"事业部"层级）
- 修改层级名称
- 调整层级顺序

**步骤3：应用层级变更**

点击"应用"按钮，系统重新计算组织架构层级。

**步骤4：验证层级变更**

在组织架构页面验证层级变更是否正确应用。

## 5. 应用管理

### 5.1 应用配置

**操作路径**：管理后台 → "应用与小程序" Tab → 添加应用

> **说明**：自建应用在管理端按创建时间排序展示。以下为企业自建应用的完整配置流程。

#### 5.1.1 创建应用

**步骤1：进入应用管理页面**

在管理后台顶部，点击"应用与小程序"标签页。

**步骤2：点击添加应用**

在应用列表页面右上角，点击"添加应用"按钮。

**步骤3：上传应用Logo**

上传应用的Logo图标，建议尺寸为 **750×750像素**，支持PNG/JPG格式。

**步骤4：填写基本信息**

| 字段名称 | 填写说明 | 是否必填 |
|---------|---------|---------|
| 应用名称 | 应用显示名称 | 是 |
| 应用介绍 | 应用功能描述，便于用户了解应用用途 | 否 |

**步骤5：设置可见范围**

配置应用的可见范围，可按以下方式设置：
- **按部门配置**：选择指定部门，该部门及下属部门的员工可见
- **按人员配置**：搜索并添加指定员工
- **全员可见**：所有员工均可查看该应用

**步骤6：创建应用**

确认信息填写无误后，点击"创建"按钮，系统自动创建应用并进入应用详情页。

#### 5.1.2 应用详情配置

应用创建成功后，在应用详情页可进行以下配置：

**1. 收发消息设置**

配置应用的消息收发能力，包括：
- 应用可接收的消息类型
- 应用主动推送消息的配置
- 消息回调地址设置

**2. 应用展示配置**

配置应用在客户端的展示方式，包括：
- 应用在工作台的显示位置
- 应用的入口类型（网页应用/小程序）
- 应用的访问地址

**3. 开发者功能配置**

配置应用的开发对接参数：
- 设置应用的可信域名
- 配置OAuth2.0授权回调URL
- 配置事件接收URL（用于接收企业微信推送的事件）

#### 5.1.3 查看AgentID与Secret

应用创建后，需要获取应用的凭证信息（AgentID和Secret）用于开发对接。

**操作步骤**：

**步骤1：进入开发者功能**

在应用详情页，点击"开发者功能"右侧的图标，进入开发者配置区域。

**步骤2：查看AgentID**

AgentID直接展示在开发者配置页面，可直接复制使用。

**步骤3：查看Secret**

> **安全机制说明**：出于安全考虑，Secret **不会直接展示**在管理端页面。

查看Secret的操作流程：
1. 在开发者配置页面，点击Secret旁的"查看"按钮
2. 系统向管理员的**移动端元信客户端**发送确认请求
3. 管理员在**客户端侧**进行确认查收
4. 确认后，Secret在客户端中显示

> **注意**：Secret是应用的重要凭证，请妥善保管，切勿泄露给无关人员。如Secret泄露，应立即在管理端重置。

### 5.2 网页授权及JS-SDK安全配置

在进行网页应用开发时，需要完成以下安全配置，以确保应用能正常调用企业微信相关接口。

#### 5.2.1 配置可信IP白名单

**操作路径**：应用详情 → 开发者功能 → 可信IP

**操作步骤**：

**步骤1：进入可信IP配置页面**

在应用详情页的"开发者功能"配置区域，找到"可信IP"设置项。

**步骤2：添加IP地址**

填写需要访问企业微信服务器地址的服务器IP地址。配置后，仅允许来自这些IP的请求调用企业微信API。

> **说明**：请确保填写的是应用后端服务器的**出口IP**，而非前端用户IP。

#### 5.2.2 配置网页授权及JS-SDK安全域名

**操作路径**：应用详情 → 开发者功能 → 网页授权及JS-SDK

**操作步骤**：

**步骤1：进入安全配置页面**

在应用详情页的"开发者功能"配置区域，找到"网页授权及JS-SDK"设置项。

**步骤2：配置授权回调域名**

填写需要从企业微信跳转的前端页面的域名和端口（支持IP地址形式），用于OAuth2.0网页授权流程。

> **注意**：
> - 域名不带协议前缀（如填写 `oa.gyzq.com`，而非 `https://oa.gyzq.com`）
> - 如使用非标准端口，需带上端口号（如 `192.168.1.100:8080`）
> - 配置后，企业微信仅允许跳转到该域名下的页面

### 7.3 权限继承规则

**规则1：角色权限继承**

下级角色自动继承上级角色的所有权限，但可以额外添加本级特有权限。

**规则2：用户权限叠加**

用户同时拥有多个角色时，权限取并集（即拥有所有角色的权限总和）。

**规则3：数据权限限制**

数据权限范围受组织架构层级限制，下级管理员的数据权限范围不得超过上级管理员。

**规则4：特殊权限覆盖**

某些特殊权限（如系统管理员权限）不受继承规则限制，需单独授权。

## 10. 常见管理问题

### 10.1 用户管理问题

**问题1：用户无法登录系统**

**可能原因**：
1. 用户账户被禁用
2. 用户密码错误或过期
3. 用户未分配角色权限
4. 用户不在系统白名单内

**解决方案**：
1. 检查用户状态，确保为"启用"状态
2. 重置用户密码，或检查密码有效期
3. 为用户分配适当的角色权限
4. 检查系统白名单设置

**问题2：批量导入用户失败**

**可能原因**：
1. Excel模板格式错误
2. 工号重复
3. 必填字段缺失
4. 数据格式不符合要求

**解决方案**：
1. 重新下载最新模板，按格式填写
2. 检查工号唯一性，删除重复记录
3. 检查必填字段是否完整
4. 检查手机号、邮箱等字段格式

### 10.2 部门管理问题

**问题1：无法删除部门**

**可能原因**：
1. 部门下存在子部门
2. 部门下存在用户
3. 部门为系统必需部门

**解决方案**：
1. 先删除或迁移子部门
2. 先迁移或禁用部门下用户
3. 系统必需部门无法删除，只能修改

**问题2：组织架构显示异常**

**可能原因**：
1. 部门层级设置错误
2. 部门编码冲突
3. 缓存数据未更新

**解决方案**：
1. 检查部门层级设置，调整层级关系
2. 检查部门编码唯一性，修复冲突
3. 清除系统缓存，刷新页面

### 10.3 应用管理问题

**问题1：应用无法访问**

**可能原因**：
1. 应用状态为"下架"
2. 应用访问地址错误
3. 用户未分配应用权限
4. 网络连接问题

**解决方案**：
1. 检查应用状态，确保为"上架"
2. 检查应用访问地址是否正确
3. 为用户分配应用访问权限
4. 检查网络连接，确保可访问应用地址

**问题2：应用权限配置不生效**

**可能原因**：
1. 权限配置未保存
2. 用户未重新登录
3. 缓存数据未更新

**解决方案**：
1. 检查权限配置是否已保存
2. 建议用户重新登录系统
3. 清除系统缓存，刷新页面

### 10.4 权限管理问题

**问题1：用户权限不足**

**可能原因**：
1. 用户未分配相应角色
2. 角色权限配置不完整
3. 数据权限范围限制

**解决方案**：

2. 检查角色权限配置，补充缺失权限

**问题2：权限变更不生效**

**可能原因**：
1. 权限变更未保存
2. 用户会话未刷新
3. 系统缓存未更新

**解决方案**：
1. 检查权限变更是否已保存
2. 建议用户重新登录系统
3. 清除系统缓存，刷新页面

1. 检查设置是否已保存
2. 清除系统缓存，刷新页面
3. 根据提示重启相关服务

**问题2：菜单显示异常**

**可能原因**：
1. 菜单配置错误
2. 菜单权限配置问题
3. 缓存数据未更新

**解决方案**：
1. 检查菜单配置，修复错误
2. 检查菜单权限配置

## 14. 门户中心管理

### 14.1 概述

门户中心是智能门户平台的核心功能模块，用于管理企业工作台的创建、配置、发布和运营。管理员可以通过门户中心创建适配不同终端（移动端和桌面端）的工作台，配置各类组件展示企业应用和信息，并管理数据源和统计分析。

**主要功能模块**：
- H5工作台管理
- 原生工作台管理
- 数据源设置
- 统计分析
- 门户模板管理
- 自定义组件管理

### 14.2 H5工作台管理

#### 14.2.1 创建标准工作台

**操作路径**：门户中心 → H5工作台 → 创建工作台

**操作步骤**：

1. 进入门户中心页面后，点击"创建工作台"，可选择以下两种创建方式：
   - **从空白创建**：在弹出页填写工作台名称，选择发布类型为"标准工作台"，选择发布平台与封面图内容。
   - **从模板创建**：需要选择模板，并填写基础信息。

2. 保存基本信息后进入工作台设计页面进行内容配置，根据业务需求，自由拖拽左侧的组件放入中间模拟画布区进行配置，并设置右侧的组件参数。

3. 选择发布平台：
   - **移动端**：可选[企业微信]
   - **PC桌面端**：可选[企业微信]、[web浏览器]
   
   > **说明**：设计面板和工作台需要开启对应的终端按钮才显示。

#### 14.2.2 移动端配置

**页面/主题设置**：

**页面属性配置**：
- **页面组件排序**：开启后，允许用户个人自由排序/隐藏页面组件。
- **搜索**：开启后，选择配置好的数据源，用户在使用工作台时，就能使用搜索功能。
- **消息**：启用后，用户可在工作台上查看各个应用及管理后台发送的消息。
- **分页**：可设置工作台内按照分页展示不同的组件，满足不同的业务场景。可通过切换Tab的方式切换分页，共可设置3个分页。

**主题选择**：
- **主题色**：提供了8种主题色以供选择。
- **头部样式**：启用后，可选择头部样式效果。若不启用，则不显示头部。

**头部设置**：
点击头部，可设置：
- **头部背景**：点击后可上传图片，替换背景。
- **用户信息**：开启后，头部可显示用户的名称。
- **天气定位**：当在系统管理中开启了天气信息时，可在此处启用天气定位，启用后可在头部显示天气及定位信息。
- **文字颜色**：可修改头部文字的颜色。

**保存与发布**：
1. 配置完成后，点击"保存"将工作台页面内容进行保存，工作台无自动存储机制，要注意不要丢失操作。

### 14.3 原生工作台管理

#### 14.3.1 创建组件

**功能描述**：用户登录系统后，进入"原生工作台"页面进行自定义组件创建与配置，选择一种自定义组件并绑定对应的应用、配置相关参数，完成后进行保存。

**操作步骤**：
1. 进入"原生工作台"的设置页面后选择一项组件类型，系统提供多种模板，点击左侧组件栏里的"+"进行创建。
2. "图片型"、"关键数据型"、"列表型"为常规类型；"webview"类型为特殊类型，系统提供5类模板匹配常用业务。注意，"webview"类型因鉴权限制，产品采用无鉴权方案进行数据发布，故不建议与数据私密性较高的信息应用对接。
3. 组件设置参数，选择一个绑定应用（该设置决定原生工作台里哪个应用变为自定义展示模块）。注意，已被其他组件绑定的应用不可再选中。
4. 数据来源分两种情况，"webview"类型除"自定义页面"外，其余均需要选择绑定一个已创建的数据源，用数据源的接入模式；点击"保存"完成自定义组件的创建。
5. 其余"图片型"、"关键数据型"、"列表型"，只需绑定应用，在点击"保存"后，系统生成对接信息（接口请求URL与秘钥），提供给应用方进行API的开发，通过调用该接口实现推送数据。

**功能描述**：用户登录系统后，进行原生工作台里的组件编辑操作，可修改组件的参数、完成后组件信息更新，仅"未发布"的组件可编辑。

**操作步骤**：
1. 点击选中一个已创建的组件，在右边参数设置部分进行编辑，修改设置的参数。注意，仅"未发布"的组件可编辑，已发布的组件需要"撤销发布"才能编辑。

#### 14.3.3 删除组件

**功能描述**：用户登录系统后，进行原生工作台里的组件删除操作，删除后组件消失，仅"未发布"的组件可删除。

**操作步骤**：
1. 点击选中一个已创建的组件，在选中框右上角点击"删除"图标，进行删除操作。注意，仅"未发布"的组件可删除，已发布的组件需要"撤销发布"才能删除。

#### 14.3.4 查询组件

**功能描述**：用户登录系统后，进行原生工作台里的组件查询操作，可按组件绑定的应用名称进行数据筛选，也支持按组件类型进行过滤。

**操作步骤**：
1. 页面左边是组件栏，上方有查询输入框，输入查询目标的"应用名称"进行查询。也可以按类型进行数据过滤。

#### 14.3.5 发布/撤销组件

**功能描述**：用户登录系统后，进行原生工作台里的组件发布操作，点击"发布"后，组件会通过接口推送至企业微信原生工作台上，将绑定的应用从图标变为自定义展示模块。

**操作步骤**：
1. 点击选中一个已创建的组件，在右侧设置信息面板里，点击"发布"，进行发布操作。发布成功后，企业微信原生工作台上，将绑定的应用从图标变为自定义展示模块。自定义组件可见权限与绑定的应用可见权限一致无需再次设置。
2. 撤销发布操作，将组件变回"未发布"状态；并且企业微信原生工作台上，将绑定的应用从自定义展示模块变回图标。

**功能描述**：自定义组件发布至企业微信后，因本质是通过接口推送至企业微信，所以模块管控权不在工作台系统，需要到企业微信后台进行调序；调整原生工作台的组件排布。

**操作步骤**：

2. 用企业微信管理员身份的账号登录【企业微信管理后台】，点击"我的企业"，再点击"工作台管理"，点击"修改应用分组"。

### 14.4 数据源设置

#### 14.4.1 创建自建数据源

**功能描述**：输入数据源的配置信息，完成后可使用该数据源，在配置工作台时可作为组件的数据来源，数据源类型不一样，设置参数会有一些细微差别。

**配置说明**：
1. 可以设置数据源共享属性，共享属性影响管理员配置工作台时选择页里的可见性，"私有"仅创建者可见，"共享"全员可见。
2. 可以配置数据源数据获取方式，"接收推送"形式的数据源一般用于实时性不强的场景，由应用方请求接口，推送数据，组件再读取展示；"主动请求"形式的数据源一般用于实时性要求较高的场景，由工作台主动请求应用方接口获取数据展示。
3. "接收推送"形式的数据源可以设置IP白名单，未设置时，所有获取API的应用方都可以调用对接推送数据，若需要限制，则可设置白名单，在白名单内的IP地址才能请求调用API对接推送数据。
4. "主动请求"形式的数据源需要填写对方的API地址，若有特定参数的话，也需要填写记录作为请求参数。

**操作步骤**：
1. 进入数据源设置页面后选择一项组件类型，点击"创建数据源"。
2. 要依次填写基础信息、获取API接口凭证、验证数据源。（验证数据源为非必要选项）
   - **填写基础信息**：弹出的创建信息页里填写数据源名称、描述、使用权限（仅个人代表仅自己可在搭建工作台时使用该数据源，全员共享代表所有管理员可使用，部分人共享代表选中的管理员可使用。）、选择获取数据方式（"接收推送"形式的数据源由应用方请求接口，推送数据，组件再读取展示；"主动请求"形式的数据源由工作台主动请求应用方接口获取数据展示）。
   - **填写高级参数**：IP白名单（"接收推送"形式的数据源特有参数，默认全开放，设置后则只对设置的IP开放）、API地址（"主动请求"形式的数据源特有参数，填写数据方提供的API地址）、传参（"主动请求"形式的数据源特有参数，填写除组件接口标准参数外的额外参数）。
   - **验证数据源**：填入用户参数值，点击左上角"点击验证"按钮，即可验证数据源连接结果。返回结果有数据正常返回表示该数据源连接正常且有数据返回，可切换其他tab看返回代码信息及组件预览效果。
3. 点击"完成"，完成数据源的创建操作，生成一条新的数据源数据。

#### 14.4.2 编辑自建数据源

**功能描述**：修改数据源的配置参数信息，完成后可更新该数据源的信息。

**操作步骤**：
1. 进入数据源设置页面后选择一项组件类型，在列表里选择一条数据源点击可打开编辑页。
2. 弹出的编辑信息页里依次修改数据源名称、描述、应用主页、属性、获取数据方式等内容。
3. 点击"保存"完成编辑操作。

#### 14.4.3 删除数据源

**功能描述**：进行删除数据源操作，删除后该数据源消失，并清除已接入推送的相关数据。

**操作步骤**：
1. 进入数据源设置页面后选择一项组件类型，在列表里，鼠标移入一条数据源的卡片上，右下角部分出现的功能菜单点击"删除"。
2. 在弹出的确认对话框里选择"确定"，删除该数据源。

#### 14.4.4 查询数据源

**功能描述**：可按数据源名称模糊检索进行数据筛选，可按数据源推送方式、共享属性、修改创建时间及验证状态这几个维度进行数据筛选。

**操作步骤**：
1. 进入数据源设置页面，根据查询需要进行查询。
2. 可以点击"全部方式"，选择全部方式/接收推送/主动请求进行数据筛选查看。
3. 可以点击"最新修改"，选择最新修改/最新创建进行数据排序。
4. 可以点击"全部状态"，选择验证通过/验证异常/验证失败进行数据筛选查看。
5. 可以输入工作台名称进行模糊检索查看。

#### 14.4.5 清理数据源/查看清理记录

**功能描述**："接收推送"形式的数据源特有功能；用户可对数据源进行清理操作，设置想要清理的截止日期时间点，执行清理任务，系统会将该日期时间点之前接收到的数据都清理掉；并且可查看历次的清理操作记录。

**操作步骤**：
1. 进入数据源设置页面后选择一项组件类型，在列表里，鼠标移入一条"接收推送"类数据源的卡片上，右下角部分出现的功能菜单点击"清除数据"。
2. 输入想要清理已接入数据的传输截止时间。
3. 点击"清理"，执行清理操作。
4. 清理完成后，可点击"查看清理记录"进行查看；若想查看历史操作也在该页面查看。

#### 14.4.6 获取API

**功能描述**："接收推送"形式的数据源特有功能；创建完的数据源需要提供api给应用方对接推送数据，系统生成API的地址和秘钥secret作为对接和鉴权依据。

**操作步骤**：
1. 选中某个数据源详情页，进入下一步。
2. 显示API的地址和秘钥信息，可以点击复制接口url和secret使用。

#### 14.4.7 官方数据源

   - **信息列表**：

     - SaaS云大学：场景：信息列表组件内，查看道一云大学应用内的消息。前提：需同时使用"道一云大学"SaaS版，并在初始化时让运维设置好对应参数。
     - SaaS新闻公告：场景：信息列表组件内，查看道一云新闻公告应用内的消息。前提：需同时使用"道一云新闻公告"SaaS版，并在初始化时让运维设置好对应参数。
   - **日程提醒**：
     - 智能门户日程中心：场景：在日程组件内，查看对应日程应用内的日程，并可跳转到对应日程详情。前提：需在部署门户时，同时部署"智能门户日程中心"私有化版本。

     - 门户待办中心：场景：在统一待办组件内，查看由"道一云统一待办"提供的待办数据。前提：需在部署门户时，同时部署"智能门户待办中心"私有化版本。

   - **统一搜索**：
     - 场景：在工作台内，开启搜索功能，可针对设置好的内容完成统一搜索，如搜索应用、待办数据、新闻等其他数据。前提：需要提前配置好统一搜索的数据源，配置方式与其他的数据源略有不同，需要由企业超管与运营侧一起配置。门户自带接入门户的应用、待办、新闻资讯，若是第三方数据，需要另外对接。
2. **示例数据源**：选中后，无需设置额外参数，该数据源提供系统生成的假数据显示，绑定后在终端查看数据。

### 14.5 统计分析

**功能描述**：工作台系统自动记录各工作台的组件、应用被点击的次数，形成点击量，在后台统计分析页可查看。

**操作路径**：智能门户 → 门户中心 → 统计分析

**操作步骤**：
1. **应用访问统计**：可查看自定义工作台上应用的访问人数与访问次数。并支持点击"累加企业微信数据"，可累加上从私有化企微获取的数据进行展示。
2. **工作台组件访问统计**：可查看工作台内各个组件的访问人数与次数。
3. **用户访问统计**：可以工作台为维度查看访问人数与次数。

### 14.6 门户模板管理

#### 14.6.1 设置自建模板

**功能描述**：将一个已配置好的工作台设为模板，后续根据模板创建工作台，不需要每次从0开始搭建工作台。

**操作步骤**：
1. 在标准工作台下，点击某个工作台的【更多】，点击【设置为模板】，弹出设置弹框。
2. 在弹框中填写基本内容，点击创建，即可设置成功。模板内容包含：主题/头部/导航栏分页等内容、设计面板组件内容和位置和参数和数据源、包含自定义上传的图标、图片、文件，不包含权限相关内容。
3. 可在门户模板模块，查看本管理员设置的模板。

#### 14.6.2 查看或使用模板

**功能描述**：管理员可查看已有的模板，并在已有模板的基础上快速创建工作台。

**操作步骤**：
1. 可切换查看官方模板或自建模板、搜索模板。
2. 编辑模板信息。
3. 使用模板：
   - **方式一**：在模板中心，选择好模板后，点击【使用模板】，即可进入设计面板里，且将模板工作台的配置内容自动填充进面板。
   - **方式二**：在H5工作台模块，点击【创建工作台】，选择【从模板创建】，选择模板，填写基础信息后，可进入设计面板，且模板内容已被自动填充入内。

### 14.7 自定义组件管理

#### 14.7.1 设置自定义组件

**功能描述**：当标准组件无法满足特殊业务场景时，开发人员可根据开发指引，开发自定义组件，并将对应代码上传至智能门户以供搭建工作台使用。

**操作步骤**：
1. 研发人员根据自定义组件的开发指引编写自定义组件的代码。
2. 在智能门户"管理后台"-"门户中心"-"自定义组件管理"模块创建自定义组件，设置组件名称、使用权限（组件可被哪些管理员使用）、组件图标、上传组件包，再点击【验证】，可查看实际效果，最后点击保存，即可完成创建。
3. 当需要删除自定义组件时，可点击组件的右下角，点击【删除】，二次确认后即可删除该组件。

#### 14.7.2 使用自定义组件

**功能描述**：创建好的自定义组件，可在搭建自定义工作台时，通过拖拉拽的方式拖入到工作中使用。

**操作路径**：在工作台设计页面的组件列表中选择自定义组件。

### 14.8 注意事项

1. 工作台无自动存储机制，配置完成后需要手动点击"保存"。
2. "未发布"状态的工作台不会在运行端生效可见。
3. 只有"未发布"的工作台可以被删除，发布的工作台需要撤销后才能删除。
4. 移动端仅出现应用中心里分类为"企业微信"类的应用。
5. "webview"类型组件因鉴权限制，产品采用无鉴权方案进行数据发布，故不建议与数据私密性较高的信息应用对接。
6. 已被其他组件绑定的应用不可再选中。
7. 原生工作台组件发布后，调整排序需要到企业微信管理后台进行。
8. 官方数据源需要满足特定前提条件才能使用。
9. 数据源清理操作不可逆，会清除截止日期之前的所有数据。

## 15. 新闻公告管理

### 15.1 概述

新闻公告管理模块用于管理企业内部的新闻、公告、通知等信息的发布与展示。管理员可以通过该模块创建、编辑、发布文章，管理文章分类和专栏，并控制文章的可见范围和推送消息。

**主要功能模块**：
- 文章管理
- 分类管理
- 专栏管理

### 15.2 文章管理

#### 15.2.1 新建文章

**功能描述**：支持新建一篇文章，该文章可以在PC端和移动端查看。

**操作路径**：智能门户管理后台 → 文章管理 → 新建文章

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，点击新建文章。
2. 首先需要完成基础字段设置，包括配置标题、作者、正文、附件、封面、摘要、分类以及专栏字段。
3. 支持对文章发布进行配置。其中发布对象为配置哪些用户可以在PC端或移动端查看该文章。推送消息数据源为配置哪些人能在数据源平台接收到消息提醒。当前仅支持推送至企业微信。
4. 配置完成后，支持定时发布或立即发布文章。定时发布即到达用户配置的时间后，才支持发布至PC端和移动端。立即发布即立刻将文章发布至PC端和移动端并推送消息提醒。

**配置项**：

| 配置类别 | 配置项 | 说明 |
|---------|--------|------|
| **基础字段** | 标题、作者、正文、附件、封面、摘要、分类、专栏 | 文章的基本信息 |
| **发布配置** | 发布对象 | 配置哪些用户可以在PC端或移动端查看该文章 |
| | 推送消息数据源 | 配置哪些人能在数据源平台接收到消息提醒（当前仅支持推送至企业微信） |
| **发布方式** | 定时发布 | 到达用户配置的时间后，才支持发布至PC端和移动端 |
| | 立即发布 | 立刻将文章发布至PC端和移动端并推送消息提醒 |

#### 15.2.2 编辑文章

**功能概述**：支持修改一篇文章，修改后该文章可以在PC端和移动端查看。

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，找到有编辑权限且处于下线状态或草稿状态下的文章，点击后方的更多按钮，点击编辑。
2. 进入文章编辑页面后，支持修改文章基础字段以及文章发布配置。包括标题、作者、正文、发布对象、推送消息等字段。
3. 修改完成后，支持定时发布或立即发布文章。

#### 15.2.3 删除文章

**功能概述**：支持删除一篇下线或草稿状态的文章，删除后文章在文章列表中消失，用户将无法找回该文章。

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，找到有编辑权限且处于下线状态或草稿状态下的文章，点击后方的更多按钮，点击删除。
2. 系统弹出提示窗，点击确定，即可完成文章删除操作。

#### 15.2.4 下线文章

**功能概述**：支持将一篇上线状态的文章进行下线，下线后，普通员工将无法在PC端或者移动端查看该文章。

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，找到有编辑权限且处于上线状态下的文章，点击后方的更多按钮，点击下线。
2. 系统弹出提示窗，点击确定，即可完成文章下线操作。

#### 15.2.5 上线文章

**功能概述**：支持将一篇下线状态的文章进行上线，上线后，普通员工将在PC端或者移动端能查看该文章。

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，找到有编辑权限且处于下线状态下的文章，点击后方的更多按钮，点击上线。
2. 系统弹出提示窗，点击确定，即可完成文章上线操作。

#### 15.2.6 文章授权

**功能概述**：支持将文章授权给其他管理员，让其他管理员对此文章拥有查看、编辑、授权权限。

**操作步骤**：
1. 进入智能门户管理后台-文章管理界面，找到有授权权限的文章。点击后方的更多按钮，点击授权。默认情况，文章创建人和后台超级管理员有该文章的授权权限。
2. 支持修改查看权限、编辑权限、授权权限管理员。超管和文章创建人不支持修改。
   - 拥有查看权限的管理员支持在文章列表查看该文章以及查看文章详情。
   - 拥有编辑权限的管理员支持对此文章进行编辑、删除、上线、下线等操作。
   - 拥有授权权限的管理员支持对文章进行授权。
3. 点击保存，文章授权修改完成。

#### 15.2.7 查看文章

**后台查看文章**：
1. 在文章列表中找到需要查看的文章，点击后方的更多按钮，点击查看。
2. 此时页面侧边栏展开，用户支持查看ID、标题、摘要、正文等字段。

**PC端查看文章**：
1. **方式1**：当该员工处于消息推送对象中时，在企业微信中将会收到该文章的消息提醒。点击消息提醒，将跳转至文章详情页中，查看文章详情。
2. **方式2**：当员工处于文章发布对象中时，在首页中可以查看到该文章，点击文章列表中的文章后，跳转至文章详情页。
3. **方式3**：当文章有配置专栏时，进入PC端-专栏页中，点击文章所属专栏，进入专栏详情页面。在专栏详情页面中点击相应的文章，支持跳转至文章详情中。

**移动端查看文章**：
1. **方式1**：当该员工处于消息推送对象中时，在企业微信中将会收到该文章的消息提醒。点击消息提醒，将跳转至文章详情页中，查看文章详情。
2. **方式2**：当员工处于文章发布对象中时，在首页中可以查看到该文章，点击文章列表中的文章后，跳转至文章详情页。
3. **方式3**：当文章有配置专栏时，进入移动端-专栏页中，点击文章所属专栏，进入专栏详情页面。在专栏详情页面中点击相应的文章，支持跳转至文章详情中。

### 15.3 分类管理

#### 15.3.1 新建分类

**功能描述**：支持新建一个分类，该分类可以在PC端和移动端查看。

**操作路径**：智能门户管理后台 → 配置中心 → 分类管理 → 新建分类

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，点击新建分类。
2. 新建分类需要填写分类名称、父级分类和分类状态。当不选择父级分类时，该分类为一级分类。当选择了父级分类后，该分类为选中的父级分类下的二级分类。
3. 点击保存，新建分类完成。

**配置项**：
- 分类名称
- 父级分类（可选）
- 分类状态

#### 15.3.2 编辑分类

**功能描述**：支持对分类进行修改，修改后可以在PC端和移动端查看新的分类。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，选择拥有分类编辑权限的分类，点击分类后方的更多按钮，点击编辑按钮。
2. 此时支持修改分类名称与分类状态。修改完成后，点击右下方的提交即可完成修改。

#### 15.3.3 删除分类

**功能描述**：支持删除没有所属文章的分类，删除后PC端和移动端无法查看到分类。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，选择拥有分类编辑权限的分类，点击分类后方的更多按钮，点击删除按钮。
2. 系统弹出提示窗，点击确定，即可完成删除分类操作。

**限制条件**：只能删除没有所属文章的分类。

#### 15.3.4 禁用分类

**功能描述**：支持禁用分类，分类禁用后PC端和移动端无法查看到分类，该分类下的文章能正常阅读。在后台新建文章时也不支持选择该分类。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，选择拥有分类编辑权限的分类，点击分类后方的更多按钮，点击禁用按钮。
2. 系统弹出提示窗，点击确定，即可完成分类禁用操作。
3. 分类被禁用后，后方会出现【禁】字图标。

#### 15.3.5 启用分类

**功能描述**：支持启用分类，启用后PC端和移动端可以查看到分类，在后台新建文章时也能查看到该分类。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，选择拥有分类编辑权限的分类，点击分类后方的更多按钮，点击启用按钮。
2. 系统弹出提示窗，点击确定，即可完成分类启用操作。

#### 15.3.6 分类授权

**功能描述**：支持将分类授权给其他管理员，让其他管理员对此分类拥有编辑、授权权限。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-分类管理界面，选择拥有分类授权权限的分类，点击分类后方的更多按钮，点击授权按钮。默认情况，分类创建人和后台超级管理员有该分类的授权权限。
2. 支持修改编辑权限、授权权限管理员。超管和分类创建人不支持修改。
   - 拥有编辑权限的管理员支持对此分类进行编辑、删除、启用、禁用等操作。
   - 拥有授权权限的管理员支持对分类进行授权。

### 15.4 专栏管理

#### 15.4.1 新建专栏

**功能描述**：支持新建一个专栏，该专栏可以在PC端和移动端查看。

**操作路径**：智能门户管理后台 → 配置中心 → 专栏管理 → 新建专栏

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，点击新建专栏。
2. 新建专栏需要填写专栏名称、专栏封面、专栏描述以及状态。
3. 点击保存，新建专栏完成。

**配置项**：
- 专栏名称
- 专栏封面
- 专栏描述
- 状态

#### 15.4.2 编辑专栏

**功能描述**：支持对专栏进行修改，修改后可以在PC端和移动端查看新的专栏。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，选择拥有专栏编辑权限的分类，点击分类后方的更多按钮，点击编辑按钮。
2. 此时支持修改专栏名称、专栏描述、专栏封面和专栏状态。修改完成后，点击右下方的提交即可完成修改。

#### 15.4.3 删除专栏

**功能描述**：支持删除专栏，删除后PC端和移动端无法查看到专栏。若专栏下仍有文章，则文章所属专栏将减少被删除的专栏，专栏仍然支持被删除。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，选择拥有专栏编辑权限的分类，点击分类后方的更多按钮，点击删除按钮。
2. 系统弹出提示窗，点击确定，即可完成删除专栏操作。

#### 15.4.4 禁用专栏

**功能描述**：支持禁用专栏，专栏禁用后PC端和移动端无法查看到专栏，该专栏下的文章能正常阅读。在后台新建文章时也不支持选择该专栏。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，选择拥有专栏编辑权限的专栏，点击专栏后方的更多按钮，点击禁用按钮。
2. 系统弹出提示窗，点击确定，即可完成专栏禁用操作。
3. 专栏被禁用后，后方会出现【禁】字图标。

#### 15.4.5 启用专栏

**功能描述**：支持启用专栏，启用后PC端和移动端可以查看到专栏，在后台新建文章时也能查看到该专栏。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，选择拥有专栏编辑权限的专栏，点击专栏后方的更多按钮，点击启用按钮。
2. 系统弹出提示窗，点击确定，即可完成专栏启用操作。

#### 15.4.6 专栏授权

**功能描述**：支持将专栏授权给其他管理员，让其他管理员对此专栏拥有编辑、授权权限。

**操作步骤**：
1. 进入智能门户管理后台-配置中心-专栏管理界面，选择拥有专栏授权权限的专栏，点击专栏后方的更多按钮，点击授权按钮。默认情况，专栏创建人和后台超级管理员有该专栏的授权权限。
2. 支持修改编辑权限、授权权限管理员。超管和专栏创建人不支持修改。
   - 拥有编辑权限的管理员支持对此专栏进行编辑、删除、启用、禁用等操作。
   - 拥有授权权限的管理员支持对专栏进行授权。

#### 15.4.7 查看专栏

**PC端查看专栏**：
1. 进入新闻公告PC端，点击专栏tab，查看专栏列表页面。
2. 点击专栏，查看专栏详情及专栏下的文章。

**移动端查看专栏**：
1. 进入新闻公告移动端，点击专栏tab，查看专栏列表页面。
2. 点击专栏，查看专栏详情及专栏下的文章。

### 15.5 注意事项

1. 只有下线状态或草稿状态下的文章才能被编辑或删除。
2. 只有上线状态的文章才能被下线，只有下线状态的文章才能被上线。
3. 文章删除后无法找回。
4. 分类删除限制：只能删除没有所属文章的分类。
5. 分类禁用后，该分类下的文章仍能正常阅读，但新建文章时不能选择该分类。
6. 专栏删除后，若专栏下仍有文章，文章所属专栏将减少被删除的专栏。
7. 专栏禁用后，该专栏下的文章仍能正常阅读，但新建文章时不能选择该专栏。
8. 文章、分类、专栏的授权权限默认属于创建人和后台超级管理员。
9. 超管和创建人的权限不支持修改。
10. 文章推送消息当前仅支持推送至企业微信。
