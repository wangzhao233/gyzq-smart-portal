2.1 打卡模式

企业微信支持三种打卡模式（图片1）：

模式说明适用场景
固定时间上下班 ✅（当前使用）所有人按照相同时间打卡办公室坐班，朝九晚五
按排班上下班按排班结果或可选班次打卡门店/流水线，三班倒
自由上下班不固定时间，随时打卡，只统计旷工销售、计时工种
现状: 目前默认使用「固定时间上下班」模式。

五、初步判断

基于 OCR 识别结果和知识库：

  1. 打卡模式: 企微支持三种模式，"按排班上下班"和"自由上下班"为标准功能，可直接切换
  2. 一天四次卡: 截图显示的 08:30/11:30/13:00/17:00 配置标准产品支持
  3. 特殊日期: 法定节假日不打卡为标准功能；必须打卡/无需打卡日期需确认
  4. 多地点/WiFi/考勤机: 需确认企微本地版是否支持
  5. 加班规则: 企微标准版支持，本地版需确认
  6. 补卡审批: 需确认是否走企微审批流还是自建审批
  7. 数据导出: API 支持打卡记录查询和导出
⚠️ 注意: OCR 识别存在一定误差，关键时间数据建议对照原图二次确认。
