### 3.2 AI辅助搜索功能评估

#### 3.2.1 产品概述

统一搜索平台是智能门户的**增购模块**（合作方产品），提供一站式智能检索解决方案。

**核心能力**：
- 多源数据对接（数据库/文件/接口）
- 可视化配置（采集任务→索引表→搜索场景）
- 精细化检索管控（禁用词/权重/同义词）
- 全链路数据监控

#### 3.2.2 信创与非信创版本差异

| 对比维度 | 非信创版本 | 信创版本 |
|---------|-----------|---------|
| 适配场景 | 常规办公环境 | 国产化信创环境 |
| 检索范围 | 新闻、待办、标题、**文件内容** | 新闻、待办、标题、文件名（**不含内容**） |
| 配套组件 | 需额外采购 | 无需额外采购 |
| 对接要求 | 需重建索引 | 需重建索引 |

#### 3.2.3 落地路径建议

**方案一：信创版统一搜索（推荐）**
- 适用：文档内容检索需求不强
- 限制：不支持文件内容全文检索
- 优势：开箱即用，信创合规

**方案二：非信创版+独立检索**
- 适用：强依赖文件内容检索
- 方案：信创环境部署基础搜索，敏感数据区使用非信创独立检索
- 风险：架构复杂，数据隔离成本

**方案三：自研AI搜索增强**
- 适用：需语义检索、智能问答
- 技术：RAG+大模型（需额外算力）
- 工作量：60-80人天（不含模型部署）

#### 3.2.4 评估结论

| 评估项 | 结论 |
|-------|------|
| 技术可行性 | ✅ 可行，信创版功能受限但可用 |
| 业务满足度 | ⚠️ 需确认文件内容检索是否为刚需 |
| 实施复杂度 | 🟡 中等，需数据迁移与索引重建 |
| 建议决策 | **推荐方案一**，优先满足信创合规 |

### 3.3 微盘文档权限精细管控评估

#### 3.3.1 现状分析

企业微信微盘原生提供以下权限能力：

| 层级 | 原生能力 |
|-----|---------|
| 空间级 | 空间管理员、成员（个人/部门）、可见/不可见 |
| 文件级 | 所有者、可编辑、可查看 |
| 分享级 | 企业内分享、指定成员、链接分享（密码/有效期） |

#### 3.3.2 二期需求拆解

根据需求确认，二期需实现：

| 需求 | 技术实现路径 |
|------|-------------|
| **标签角色批量授权** | 开发"标签-权限"映射中间层，批量调用微盘API设置文件权限 |
| **门户角色体系打通** | 建立门户角色↔微盘权限的自动映射规则（如门户管理员→微盘空间管理员） |

#### 3.3.3 技术方案设计

```
┌───────────────────────────────────────────────────────────────────┐
│                      微盘权限管控增强架构                           │
├───────────────────────────────────────────────────────────────────┤
│                                                                   │
│   ┌──────────────┐      ┌──────────────┐      ┌──────────────┐   │
│   │  智能门户     │      │  权限映射    │      │  企业微信    │   │
│   │  角色体系     │─────▶│  中间层      │─────▶│  微盘API     │   │
│   │              │      │              │      │              │   │
│   │ - 管理员     │      │ - 角色映射    │      │ - 空间管理   │   │
│   │ - 普通用户   │      │ - 标签规则    │      │ - 文件权限   │   │
│   │ - 部门角色   │      │ - 批量同步    │      │ - 成员管理   │   │
│   └──────────────┘      └──────────────┘      └──────────────┘   │
│                                   │                              │
│                                   ▼                              │
│                          ┌──────────────┐                        │
│                          │   标签库     │                        │
│                          │  - 财务标签  │                        │
│                          │  - 项目标签  │                        │
│                          │  - 部门标签  │                        │
│                          └──────────────┘                        │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘
```

#### 3.3.4 功能模块设计

**模块一：角色映射管理**
| 功能 | 说明 |
|------|------|
| 角色绑定 | 门户角色与微盘权限等级的绑定配置 |
| 自动同步 | 门户角色变更时自动同步至微盘 |
| 权限继承 | 新成员自动继承角色对应的微盘权限 |

**模块二：标签权限规则**
| 功能 | 说明 |
|------|------|
| 标签创建 | 在门户侧创建标签（财务/项目/部门等） |
| 规则配置 | 标签与部门/角色的权限映射规则 |
| 批量授权 | 按标签批量设置文件权限 |
| 自动生效 | 新文件自动继承标签权限规则 |

#### 3.3.6 评估结论

| 评估项 | 结论 |
