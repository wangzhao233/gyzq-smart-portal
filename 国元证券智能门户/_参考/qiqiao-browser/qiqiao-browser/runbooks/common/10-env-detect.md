# 节点 10：环境检测（安装引导与连接诊断）

## 你在哪里

恢复协议的前置检测判定 bsk **未就绪**（`which bsk` 失败，或 `bsk status` 显示扩展未连接）时，才进入本节点。本节点负责**安装引导与连接诊断**，**不重复**前置已做的 `which bsk`。

> **入口约定**：bsk 就绪检查只在恢复协议做一次（见 GR-01-5）。本节点处理的是"检查结果为未就绪"的善后，而非再次检查。

## 本节点产出

- bsk CLI 已安装、扩展已连接，**或者**用户明确拒绝安装后终止流程

## 检测流程（仅在"需要诊断连接"时执行；命中即停）

### 检测 1：bsk CLI 是否已安装？（仅当前置检测报告 `which bsk` 失败时）

| 前置检测结果 | 处理 |
|------|------|
| 前置已报告 `which bsk` 失败 | → **情况 A：安装 bsk CLI**（完整展示步骤） |
| 前置报告 bsk 已安装 | 跳到检测 2 |

### 检测 2：browser-skill 浏览器扩展是否已连接？

```bash
bsk status
```

| 结果 | 处理 |
|------|------|
| 显示已连接浏览器 | ✅ 环境就绪 → **节点 20（登录）** |
| 显示 `0 browsers connected` 或扩展未连接 | → **情况 B：引导安装扩展**（向用户展示步骤） |

---

## ⚠️ 引导用户安装时，必须把步骤**完整显示在回复中**（不要只在思考里）

> 安装指引必须**直接展示给用户**，加粗标记关键步骤。不要把它写在思考/工具调用里然后只回一句"请安装扩展"。

---

## 情况 A：bsk CLI 未安装 — 完整展示给用户

**直接复制以下内容回复用户：**

---

> **请安装 bsk CLI 工具，用于控制浏览器自动化。** 共有三种方式，按省事程度排序：
>
> **方式一（让 Agent 直接帮你安装，最省事）**：
> 如果你不想手动敲命令，直接回一句"**帮我安装**"或"**你来装**"即可。
⚠️ 后续如果浏览器扩展未连接（`browsers connected: 0`），**无需再去下载**——技能文件夹里已备好 `BrowserSkill 0.1.3.crx` 文件，直接拖入扩展页即可。
>
> **方式二（自动安装脚本，你自己执行）**：
> ```bash
> curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
> ```
> ⚠️ `raw.githubusercontent.com` 在国内可能无法访问，失败请用方式三。
>
> **方式三（手动下载）**：
> 1. 前往 [BrowserSkill GitHub Releases](https://github.com/Tencent/BrowserSkill/releases) 下载对应系统的 bsk 二进制
> 2. 将 bsk 放到 PATH 下（如 `/usr/local/bin/` 或 `~/.local/bin/`）
> 3. 验证安装：`bsk --version`
>
> 方式二/三安装完成后执行：
> ```bash
> bsk install-skill --yes
> ```
>
> 完成后告诉我"bsk 已安装"。

---

## 情况 B：浏览器扩展未安装 — 完整展示给用户

**直接复制以下内容回复用户：**

---

> **请安装 BrowserSkill 浏览器扩展，bsk CLI 已就绪。**
>
> 请按以下步骤操作：
>
> **1. 打开 Chrome/Edge 扩展页**：在地址栏输入 `chrome://extensions/`（Edge 用 `edge://extensions/`）
>
> **2. 开启开发者模式**：点击页面右上角的 **「开发者模式」** 开关
>
> **3. 拖入扩展文件**：将技能文件夹里的 `BrowserSkill 0.1.3.crx` 文件拖入扩展程序页面，**扩展文件已存放在技能文件夹里**
>
> **4. 检查图标颜色**：安装后点击扩展图标，确保图标变为**绿色（已连接）**
>
> **5. 完成告诉我**：返回后告诉我"扩展已安装"，我会继续下一步。
>
> 💡 如果拖入 `.crx` 无效：可把 `.crx` 改名为 `.zip` 解压，再点「加载已解压的扩展程序」选解压目录。

---

## 操作失败处理

| 失败场景 | 处理方式 |
|----------|---------|
| curl 下载失败（网络问题） | 重新向用户展示方式二手动下载步骤 |
| `bsk status` 显示异常 | 重新向用户展示扩展安装步骤 + 建议运行 `bsk doctor` 诊断 |
| 用户拒绝安装 | 终止流程，告知用户无法在没有 browser-skill 的情况下操作七巧平台 |
